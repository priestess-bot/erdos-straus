# Type I 自适应逃逸深度在千万级种子中可达九十七窗口

## 审计定义

先从 \(p\le10^7\) 的核心素数中选取所有在

\[
m=3,7,11,15,19,23,27,31 \tag{1}
\]

均没有 Type I 证书的点，共 84 个。对每个种子，采用一私有素因子模型

\[
x_j=E_jL_j,
\]

并在加入每个新缺口时按以下确定性规则选择状态：

1. 枚举新缺口的残数类并取第一个仍避开 Type I 目标 \(-1/4\) 的类；
2. 若仿射素数形式有局部覆盖素数，递归拆分，深度最多为 8；
3. 保留第一个局部可采纳的分支。

若没有这样的分支，则对新缺口的全部残数类检查完整的一私有素因子平方除子残数模型。

## 结果

| 项目 | 数值 |
|---|---:|
| 初始种子 | 84 |
| 审计窗口上限 | 100 |
| 在上限内关闭的所选链 | 84 |
| 最小关闭窗口 | 8 |
| 最大关闭窗口 | 97 |
| 最深种子 | 776,521 |
| 最深终止缺口 | 391 |

深度 50 以上的所选链并不罕见于这一小样本：其关闭窗口为

\[
53,57,59,71,71,85,89,97. \tag{2}
\]

所以第八或第二十三窗口的闭合不能代表统一的低深度机制。

在这八条长链中，每条最终状态的碰撞固定因子至少含四种不同素因子，且至少经历两次
八窗口之后的局部覆盖拆分；最深链的相应数值为五种和四次。这只是有限相关性，不是
必要条件的证明，但它明确了应先攻击的有界复杂度子类。

对全部最终失败位置作子群--积集分流后，1,752 个位置的目标残数根本不在素因子生成
子群中，只有 403 个位置虽在子群中却受有限幂指数阻挡。精确的角色翻译见
[Type I 子群--字符分流](type-I-subgroup-character-obstruction.md)。
后一个有限积集类中，350 个位置已满足“私有残数商阶至多3”而只缺固定因子饱和；
严格的三余类闭合判据见
[Type I 三余类饱和](type-I-one-private-three-coset-saturation.md)。
按私有因子平移首达指数再细分后，121 个位置只差指数3、235个需要至少指数4、47个
对同一私有因子的所有幂都无效，见
[Type I 私有平移首达判据](type-I-private-translate-index.md)。

另一方面，种子 \(806521\) 的所选链完成第23窗口、终止于 \(m=95\)，且其23个失败
位置全部为子群型、积集型为零。它是固定窗口纯字符条件逃逸的具体模型见证，说明筛界
提供的是平均稀薄性而非逐点闭合。

## 含义

本剖面同时排除两种不充分的研究直觉：

- 不能因为若干初始状态在 \(m=35\) 闭合，就猜测固定小窗口总会关闭；
- 也不能因为一条状态逃过几十个缺口，就把它当作无限逃逸的证据。

值得证明的量不应是一个预先固定的窗口长度，而应是与状态相关的复杂度，例如碰撞因子
\(E_j\) 的素因子结构、私有素因子数、局部拆分深度或残数积集大小。一个有价值的势函数
应能证明：若窗口持续扩张且 Type I 目标仍被避开，则这些复杂度中至少一个严格增长；
再将该增长与算术级数、可采纳性或因子结构矛盾结合。

## 边界

所有结论限于实际有限种子、首残数选择和一私有素因子模型。不同残数选择可能产生不同
链；多私有因子、非仿射因子或超过拆分深度的局部状态没有被排除。因此它不能证明
Erdős--Straus 猜想，也不能证明全部条件逃逸会在有限深度关闭。
