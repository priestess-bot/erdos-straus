# H19 残余的旧私有因子释放审计

## 问题

[自适应新因子过渡谱](type-II-adaptive-factor-transition.md) 在两千万范围的前十九条
规范 Type II 射线共同失败点中，发现绝大多数点在第一个后续成功移位已经有不含旧私有
因子的证书。这里把审计扩至一亿，并检验首个成功移位的旧私有因子复用是否会在扩张扇后
持续存在。

旧私有因子的定义固定为 H19 中所有 \(p+4s\)（\(1\le s\le19\)）的非碰撞因子；
在每个新移位完整枚举 Type II 除子证书，并要求选中的证书旧私有重数为零。

## 一亿审计

运行：

    python3 reproductions/type_ii_old_private_release.py \
      --limit 100000000 --base-shift-bound 19 \
      --first-shift-cap 50 --release-shift-cap 125

得到：

| \(p\) | 首个成功移位与证书因子 | 初始窗后首个无旧私有移位与因子 |
|---:|---|---|
| 3,361 | \(29,1159\) | \(125,99\) |
| 813,121 | \(34,35359\) | \(56,1455\) |
| 8,283,361 | \(22,703\) | \(52,103\) |
| 14,847,529 | \(29,3363\) | \(72,47\) |
| 26,722,921 | \(26,66975\) | \(63,167\) |
| 35,256,601 | \(21,269135\) | \(81,1475\) |
| 36,498,289 | \(40,26239\) | \(80,159\) |
| 36,998,641 | \(29,1159\) | \(61,672707\) |
| 48,605,881 | \(32,99807\) | \(51,2651\) |
| 52,751,329 | \(25,19\) | \(54,6335\) |
| 76,759,321 | \(32,1081119\) | \(52,131663\) |
| 83,581,801 | \(23,287223\) | \(80,31199\) |

在 \(p\le10^8\) 的审计中，164 点中 163 点已在 \(20\le s\le50\) 命中；其中 151 点
在首窗即可取旧私有重数为零的证书。唯一首窗未命中点
\[
p=81{,}846{,}241
\]
在 \(s=52\) 以 \(h=60{,}943\) 直接命中，且同样没有旧私有因子。首窗中余下 12 个
旧私有重数正的点均在 \(51\le s\le125\) 获得此类证书。因此 164 点全都在移位125前有
旧私有重数为零的 Type II 证书。特别地，\(p=3361\) 的
释放因子 \(99\) 完全来自旧碰撞部分，故“释放”并不等同于必须出现新素因子。

这里的“在 \(51\le s\le125\) 获得”是刻意从初始窗后开始的释放定义，并不是首次无旧
私有证书的深度。若对每个点直接最小化该深度，164 点中已有 162 点不晚于 \(s=50\)；
只有 \(p=81{,}846{,}241\) 在 \(s=52\)、\(p=3361\) 在 \(s=125\)，见
[首次无旧私有因子深度谱](type-II-source-free-transition-profile.md)。

## 含义与边界

这否定了一个过强但自然的候选势函数：不能以“首个后续命中是否复用旧私有因子”作为
状态难度的单调指标。更合适的对象是存在量词版本：给定当前来源标记，能否在某个可控的
后续扩扇层选择无旧私有因子的证书。若不能，才把该状态转入 Type I 的碰撞--私有积集
分析或真正可提升的递降。

该结果仅是 \(p\le10^8\)、移位至 125 的有限证据，既没有统一界也没有证明每个
新扇必释放。其价值是把下一条待证引理精确地从“首命中无复用”改成“自适应层存在无复用
证书，或状态复杂度发生可量化变化”。
