# 十九移位残余的未固定因子数边界与后续移位过渡谱

## 定义

令前十九条规范移位的联合模数为

\[
Q_{19}=77{,}597{,}520,\qquad
\mathcal P_{19}=\{2,3,5,7,11,13,17,19\}.
\]

对正整数 \(N\)，定义未固定因子重数

\[
\Omega_{\mathcal P_{19}^{\,c}}(N)
=\sum_{\substack{\ell^e\parallel N\\\ell\notin\mathcal P_{19}}}e. \tag{1}
\]

它只记录 \(N\) 中不整除联合模数的素因子。这个量是研究“模数闭包后仍剩多少私有
因子”的自然第一候选，但它本身没有编码除子残数积集。

## 精确过渡谱

对全部 \(p\le10^7\)、\(p\equiv1\pmod {24}\) 的核心素数，逐项重建前十九条规范
射线证书。45 个共同失败点随后在 \(20\le s\le50\) 全部首次命中，分布为：

| 首次后续移位 \(s\) | 点数 |
|---:|---:|
| 20 | 8 |
| 21 | 2 |
| 22 | 1 |
| 23 | 3 |
| 24 | 6 |
| 25 | 4 |
| 26 | 6 |
| 27 | 3 |
| 28 | 1 |
| 29 | 2 |
| 31 | 1 |
| 32 | 3 |
| 34 | 1 |
| 36 | 3 |
| 50 | 1 |

所以有限样本中不存在一个压倒性的“第 20 条补充移位”；后续成功移位随 \(p\) 分散。

调用

```bash
python3 reproductions/type_ii_minimal_canonical_shift.py \
  --limit 10000000 --base-shift-bound 19 --shift-cap 50 \
  --output reproductions/type-ii-canonical-h19-transition-10m-results.json
```

会重新生成完整残余、每一张后续 Type II 证书及因子统计。

## 余因子数反例

对这 45 个共同失败点，

\[
\min_{1\le s\le19}\Omega_{\mathcal P_{19}^{\,c}}(p+4s)
=\begin{cases}
0,&\text{1 个点},\\
1,&\text{44 个点}.
\end{cases} \tag{2}
\]

零值点为

\[
p=1{,}127{,}281,\qquad
p+4\cdot19=1{,}127{,}357=7\cdot11^5. \tag{3}
\]

该 \(p\) 确实逃过前十九条射线；其 \(s=19\) 移位数却完全由
\(\mathcal P_{19}\) 中的素数构成。这说明，即使模数外私有因子数为零，射线的残数
积集仍可避开目标 \(-1\)。

## 支撑结构

对 45 个残余的全部 \(45\cdot19=855\) 条失败射线，完整除子残数分析得到：

\[
\#\{\text{支撑外、二幂深度零}\}=721,\qquad
\#\{\text{支撑外、深度一}\}=6,\qquad
\#\{\text{支撑内缺陷}\}=128. \tag{4}
\]

因此大多数失败仍在最难的支撑外深度零层；仅靠二次或更高二幂字符不能统一剥离它们。
但每个 45 个目标素数都至少有一条支撑内失败射线，支撑内条数的分布为

\[
1:7,\quad2:13,\quad3:10,\quad4:12,\quad5:2,\quad7:1. \tag{5}
\]

这只是有限观察，不是“所有共同失败必有支撑内射线”的定理。它指出一个较具体的正向
接口：若能在增长移位扇中**选择**一条支撑内失败射线，便可调用补因子轨道约束；但尚无
这样的选择定理。

这个选择也不能被简化为固定小移位或小缺失集。45 个残余的最小支撑内移位分布在

\[
5,7,8,10,11,13,14,16,17,19, \tag{6}
\]

其中任一个固定移位都不覆盖全部 45 点。再在每个点的所有支撑内射线中取最小缺失集
大小，分布仍包含

\[
8:4,\ 9:1,\ 11:1,\ 13:2,\ 16:2,\ 17:1,\
20:3,\ 22:1,\ 24:2,\ 28:1. \tag{7}
\]

特别地

\[
p=8{,}243{,}041,\qquad s=19
\]

的所有支撑内射线中，最小缺失集大小仍为 \(28\)。所以
`type-II-support-defect-orbit-constraint` 的“两孔或奇孔”推论不能被一个
“总能选到小孔支撑内射线”的断言直接统一调用。

## 对研究路线的限制

由 (2)--(3)，下列看似自然的中间引理已经为假：

\[
\text{“十九移位共同失败}\Longrightarrow
\min_{s\le19}\Omega_{\mathcal P_{19}^{\,c}}(p+4s)\ge2\text{。”} \tag{4}
\]

更一般地，不能仅以未固定素因子个数设计模数闭包势函数。结合 (4)，任何可能有效的
增长引理还不能只依赖固定字符深度或小孔轨道；它必须保留至少一部分更细信息：固定
因子的完整残数积集、一般支撑内缺失集、补因子轨道，或不同移位数之间的精确差值关系。

这个有限反例不否定存在更精细的闭包稳定势函数，也不否定增长新移位的 Type II
选择器。它只排除其中最直接的 \(\Omega\)-计数强化。
