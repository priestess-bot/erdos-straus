# 素数解穷尽为 Type I 或 Type II

## 结论

对奇素数 p，交换分母后每个解恰落入 Type I（p 整除一个分母）或 Type II（p 整除两个分母）。

## 推理与来源

清分母后 p 必整除至少一个分母；若三个都被 p 整除会得到不可能的缩小关系。p 的整除指数分析排除其他型态。

- Elsholtz-Tao 2013, Section 2.
- Monks-Velingker 2008, Theorem 2.1(c)-(d).

## 边界

对合数 n 未必只有两型；Pomerance-Weingartner 给出 5/6 的反例型态。
