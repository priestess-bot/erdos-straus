# 固定多项式恒等式不能覆盖平方剩余类

## 结论

对原始剩余类，非平方类可由多项式分母统一求解；平方类不能由同一固定多项式机制覆盖。

## 推理与来源

Elsholtz-Tao 把 Schinzel 型必要条件与 Type I/II 参数化结合，并对模 840 的原始类给出现代分类。

- Elsholtz-Tao 2013, polynomial solvability theorem in Section 2 and discussion of primitive classes modulo 840.

## 边界

这是方法障碍，不说明平方类无整数解，也不排除非多项式或参数增长的构造。
