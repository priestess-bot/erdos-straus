# H19 残余的二层自适应偶源严格递降闭合

## 两层递降

第一层对每个 H19 残余遍历完整平方因子外部源扇。仅在它失败时，第二层枚举完整的奇距离
偶源扇

\[
n=p-c,\qquad c\in\{1,3,5,7\}.
\]

每个第二层候选都使用 [奇数距离偶源定理](odd-distance-even-source-descent.md) 的完整因子
参数化，并以精确有理数验证源解、目标解和严格 \(n<p\)。

## 五亿结果

第一层给出 422 个严格递降。它的三个遗漏在第二层全部闭合：

| \(p\) | 距离 \(c\) | 源分母 \(p-c\) | Type I 缺口 |
|---:|---:|---:|---:|
| \(35{,}840{,}809\) | 7 | 35,840,802 | 983 |
| \(132{,}285{,}169\) | 3 | 132,285,166 | 191 |
| \(141{,}326{,}089\) | 3 | 141,326,086 | 11 |

所以

\[
425=422+3 \tag{1}
\]

是完全由严格递降组成的有限闭合，而不再需要把这三点留给后续 Type II 短证书。

## 十亿后的边界

同一 H19 审计推至 \(p\le10^9\) 后，完整平方因子递降出现第四个遗漏
\(p=640{,}775{,}689\)。前三点仍由 \(c=7,3,3\) 处理；第四点在完整
\(c\le9999\) 奇距离偶源扇中仍未命中，却在 \(c=34091\) 首次严格提升。因此十亿
剖面同样有纯递降闭合 \(664=660+4\)，但它否定了固定小距离的外推。该点也独立具有
\(s=45,h=359\) 的纯新 Type II 证书，见
[第四压力点的偶源首释放](type-II-h19-fourth-even-source-release-boundary.md)。

## 边界时间线

同一程序的嵌套范围回放给出：

| 范围 | H19 残余 | 标准平方因子递降 | 偶源备用点 |
|---|---:|---:|---|
| \(p\le10^8\) | 164 | 163 | \(35{,}840{,}809;c=7\) |
| \(p\le2\cdot10^8\) | 255 | 252 | \(35{,}840{,}809;c=7\)，另两点 \(c=3\) |
| \(p\le3\cdot10^8\) | 328 | 325 | 与两亿范围相同的三点 |
| \(p\le5\cdot10^8\) | 425 | 422 | 与三亿范围相同的三点 |
| \(p\le10^9\) | 664 | 660 | 前三点 \(7,3,3\)，第四点 \(34091\) |

所以标准分支的首个遗漏是 \(35{,}840{,}809\)；另两点在两亿范围内出现，三亿范围没有
新增遗漏，五亿范围也没有新增遗漏。对一亿压力集把第二层截断为 \(c\le3\) 时，唯一的首遗漏
\(35{,}840{,}809\) 仍未闭合；故当前有限闭合至少需要距离 7。这是一个压力集稳定的
观测，不是对更大范围的界。

在三条压力点上逐项比较 \(c=1,3,5,7\) 还给出不可约的双分支：

| 距离 | 命中压力点数 |
|---:|---:|
| 1 | 0 |
| 3 | 2 |
| 5 | 0 |
| 7 | 1 |

\(35{,}840{,}809\) 只在 \(c=7\) 命中，另两点只在 \(c=3\) 命中。因此即使局限于
当前五亿压力集，也不能把偶源补救替换为单一距离，见
[小距离偶源不可约边界](type-II-h19-even-source-distance-boundary.md)。

## 边界

这里的距离 \(7\) 和 \(34091\) 都是在已发现的第一层遗漏上逐项扫描得到的，不是对一般
素数的固定距离定理。已有条件性逃逸结果排除把一组固定有限源当作全称证明；下一步仍需
解释：若第一层失败，为何某个依赖于状态的距离 \(c\) 必然满足偶源扇的因子同余，或该失败
如何强制零/一碰撞的新因子 Type II 证书。

对十亿四点压力集，改按尾参数 \(r\) 扫描可在 \(r\le103\) 全部闭合，首命中为
\(103,31,31,15\)，但第四点仍有距离 \(34091\)。因此 \(r\) 比固定 \(c\) 更值得作为
状态变量，见 [H19 十亿压力集的小 r 偶源尾选择剖面](type-II-h19-pressure-small-r-profile.md)。
