SOURCE-MANIFEST.sha256 is the unmodified checksum manifest from that ZIP.
The original runner wrote a timing-dependent unittest transcript back to
evidence/test-report.txt, which made its own manifest fail after a second
execution. The integrated run_all.sh keeps the immutable transcript snapshot
and sends the current test output to the console instead.

The original independent replayer also used a Miller--Rabin base set that was
deterministic only below (2^{64}), without rejecting larger integers. The
integrated version instead uses its independent complete sieve factorization
path for primality at every finite input and rejects bool/float aliases for
integer state fields in both implementations.

MANIFEST.sha256 is generated for this integrated directory after these two
reproducibility and type-safety corrections. The package remains evidence-only:
it does not issue actual-source, complete-schedule registry,
successor-admission, queue, or T6 authority.

The manifest intentionally excludes interpreter cache files under __pycache__.
They are generated by the compile check and are neither source nor evidence.

The original evidence/test-report.txt remains an immutable source-package
snapshot. evidence/integration-test-report.txt records the expanded integrated
test result after the two corrections above.
