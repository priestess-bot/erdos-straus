# T5 v1 -> FULL migration

The previous v1 statement only proved a common rank for a frozen registered-edge allowlist.  FULL T5
supersedes it with a contract-level rule:

1. every persistent target must carry one canonical T5 rank;
2. only three admission tickets exist: outer-rank, phase/protocol, or local-rank drop;
3. PRE/ABSORB and legacy RESET are included in the phase registry;
4. actual ordinary positive-q G has a relative handoff and an origin-normalized first local edge
   under its recorded source receipt, while later Type-I totality remains a T6 obligation;
5. future arithmetic edges do not require a new T5 theorem: they must satisfy E1--E4 and one of the
   existing admission tickets, or remain nonrecursive.

The old v1 allowlist can remain as a regression manifest, but it is no longer the logical definition of
T5 well-foundedness.
