# SP-21/SP-22 signed policy data

`sp21-policy-registry-v1.json` canonically fixes the decidable ordinary q=1,G source predicate, the eight source actions, target terminal policy, complete overlap partition, owner route, common-admission contract and non-claims. The domain has no finite `members` list.

`sp21-artifact-lock-v1.json` fixes the executable constructor, independent replayer, policy, tests, proof dossiers, portfolio ledgers and reproduction documents by SHA-256.

`sp21-external-authority-anchor-v1.json` contains the offline coordinator's RSA-3072 public key and detached signature over the authority ID, base commit, policy digest, artifact-lock digest and explicit prohibition on producer mutation/caller authority booleans. The private key is not distributed.

This is a one-shot research authority for the exact signed slice. It does not grant authority to the production T6 runtime.
