# T2 Atomic-Admission：下一步执行规划

> 本文只定义后续研究的可执行目标与验收门，不把任何候选边升级为已完成结论。
> 当前依据截至 2026-08-17 的旗舰 T2、状态合同和已有 atomic claim。

## 结论先行

下一步不应直接试图证明“所有实际可达状态的 atomic split 都可入队”。这个量词目前没有
封闭、版本化的输入 grammar；直接攻击它会把 source provenance、candidate menu、state
serializer、局部 E5 与 T5 的全局势混成一个无法证伪的命题。

应先完成下面这个较小而可判真的目标：

为一个显式、版本化的实际 atomic 输入并集 \(\mathcal A_{\mathrm{v1}}\)，构造
deterministic admission adapter，使

\[
\mathcal A_{\mathrm{v1}}
\longrightarrow
\left\{
\text{direct terminal},\
\text{pending-dispatch target with E1--E5 classification},\
\text{rejection or boundary}
\right\}.
\]

任何 standalone stutter 均不得入队。

这个工作产出的是可供 T5 消费的**有限 edge grammar**，不是 T5 的全局良基性证明。
只有 T5 接纳相位与全局势后，局部 pending-dispatch 输出才可成为全局 verified edge。

## 本次 T2 的精确边界

纳入：

1. 有真实 persistent source、不可变 scope、可重放 raw path 与版本化 priority prefix 的
   atomic candidate。
2. canonical maximal split、target normal form、terminal-first dispatch、identity lift
   与 strict/stutter 分类。
3. 对每个声明为 owner-local 的输入 arm，证明 selector 至多消费一个 atomic action，且
   归纳规则不跨 edge 汇集容量。

不纳入：

1. T5 的全局良基势或任何未付 reset 的排除。
2. T6 的 total selector、未枚举 source family 的普遍 terminal 存在性，或
   \(c=8,q_\star=103\) image totality。
3. 非平凡 marked set 的 serializer。
4. 仅凭裸 chart、target-derived raw source 或有限 control 构造新的 state origin。

## 成功、失败与升级规则

T2 的一次有效交付必须落在下列二者之一：

1. **正面结果**：对已声明的 \(\mathcal A_{\mathrm{v1}}\) 全称证明 adapter 输出 terminal，
   或一个有完整 receipt 的局部 strict edge/guarded macro；每个非 terminal target 都带
   明确的下一步正规化要求。
2. **负面结果**：给出实际 persistent receipt 的严格反例或容量图，证明某个输入 arm
   不能通过 source、normal-form、priority 或 E5 门，并据此从
   \(\mathcal A_{\mathrm{v1}}\) 删除该 arm 或增加不可省略的前提。

下列情况都不算完成：

- 用“validator 接受时”隐藏尚未定义的 source 或 target 字段；
- 将 control-only fixture 升格为实际 recursive edge；
- 将 \(c_M=C\) 的 standalone stutter 作为 edge 入队；
- 因为一个 arm 不需要 global one-use，就宣称所有 pooled-capacity 论证都不需要 ledger；
- 在全局 phase/rank 未定义时把局部 strictness 写成 T5。

## 与 T5 的交接门

T2 只有在下列信息都被冻结后，才值得开始设计 T5 的全局势：

\[
\boxed{
\text{versioned input grammar}
\;+\;
\text{per-arm terminal/edge/reject partition}
\;+\;
\text{owner locality or explicit ledger requirement}
\;+\;
\text{strict/guarded-stutter classification}
}
\]

此时 T5 面对的是有限、可枚举的边类型，而不是不断新增的“可能 atomic action”。若 Slice 8
显示剩余问题是某个 source family 的 terminal totality、marker existence 或新算术出口，
它应移入相应的 T1/T6/q=1 子问题，不再以“Atomic-Admission 未完成”笼统表述。
