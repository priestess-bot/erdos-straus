## 0. 执行结论

项目近期取得了实质性进展，但进展的性质应准确概括为：

\[
\boxed{
\text{已经建立一套逐层压缩 F 型障碍的有限群机制，}
\quad
\text{尚未建立跨状态的算术下降。}
}
\]

当前最稳健的旗舰目标仍应是：

\[
\boxed{
\text{普通 Type II 双尾}
\quad\lor\quad
\text{一般 Type I 目标除子 + 偶终端选择器。}
}
\]

线性源、\(B=1\)、固定 AC 扇、有限层重选等，应继续作为结构实验室或可证伪强化，而不应替代一般混合终端选择器成为逻辑主线。

本轮最重要的判断有五点：

1. **近期 Kneser—稳定子商—素数阶商预算链条是正确的方向。**  
   它把“有限指数盒为什么漏掉目标”从模糊现象变成了可量化的商群缺陷。

2. **“严格下降”必须重新命名。**  
   最新稳定子商步骤严格降低的是有限群 \(|Q|\)，不是素数 \(p\)、模数 \(R\)、缺口 \(m\) 或源大小。它是“商群压缩”，尚不是 Erdős–Straus 归纳意义上的算术下降。

3. **当前私有商群定理的固定层子群假设过强。**  
   对一般固定层 \(J=\mathcal C_R(N)\)，它通常只是对称子集，不必是子群。应立即改成“固定层稳定子约化”，在不假设 \(J\) 为子群的情况下保留精确性。

4. **近期的平方盈余统计不能被解释成全局必要性。**  
   1,649 个点保存的是首次选中证书。多素因子盈余占多数，只能说明当前选择策略常用多层支持，不能说明这些素数的所有证书都必须如此。

5. **下一步最有价值的计算，不是把上界推进到 \(1.3\times10^9\)。**  
   应对困难状态做完整商群、稳定子、关系格、傅里叶谱、目标表示纤维与偶终端高度审计。

# 1. 当前证明架构

## 1.1 逻辑主干

对核心素数 \(p\equiv1\pmod{24}\)，当前仓库形成了两级出口：

\[
\boxed{
\text{普通 Type II 双尾命中}
\quad\lor\quad
\text{Type I 混合终端命中}.
}
\]

一般 Type I 混合终端判据可概括为：选择合法缺口 \(m\)，令

\[
x=\frac{p+m}{4},
\]

寻找目标平方除子 \(e\mid x^2\)，使其产生

\[
R=\frac{4e+1}{m},
\qquad
K=xR-e,
\]

随后在同一 \((R,K)\) 状态中寻找偶终端除子

\[
E\mid4K^2,\qquad
E\equiv1\pmod R,\qquad
E\le4K-2R.
\]

于是

\[
n=\frac{4K-E}{R}
\]

是更小的正偶数，并同时完成目标素数与偶终端的构造。

这里必须区分两件事：

- `type-I-target-divisor-even-terminal-selector` 已经给出**精确代数等价**；
- “每个普通 Type II 遗漏都存在这样的选择”仍然是**开放的全称存在性命题**。

## 1.2 固定状态的三分法

对固定 \((R,K)\)，令

\[
K=\prod_{i=1}^r q_i^{\nu_i},
\]

中心化平方除子谱为

\[
\mathcal C_R(K)
=
\left\{
\prod_{i=1}^r q_i^{z_i}\bmod R:
-\nu_i\le z_i\le\nu_i
\right\},
\]

素因子生成子群为

\[
\mathcal H_R(K)
=
\langle q_i\bmod R: q_i\mid K\rangle.
\]

目标状态分类为

\[
\begin{array}{ccl}
G&:&-1\notin\mathcal H_R(K),\\[1mm]
F&:&-1\in\mathcal H_R(K)\setminus\mathcal C_R(K),\\[1mm]
\mathrm{hit}&:&-1\in\mathcal C_R(K).
\end{array}
\]

这套分类现在已经稳定：

- G 型是**支撑/角色障碍**；
- F 型是**有限指数盒障碍**；
- hit 是目标平方除子存在。

近期工作的核心几乎全部集中在 F 型。

# 2. 最新提交链带来的真实增量

从此前的目标纤维和 Kneser 方向出发，最近提交形成了如下链条：

\[
\begin{aligned}
&\text{比值二除子密度}\\
&\to\text{二进截断密度}\\
&\to\text{非退化终端或标记下降}\\
&\to\text{双块/多块 Kneser}\\
&\to\text{F 型临界商分类}\\
&\to\text{单活跃素因子循环模型}\\
&\to\text{二进平衡与最近剩余类判据}\\
&\to\text{跨状态活跃素因子碰撞}\\
&\to\text{私有指数盒商群饱和}\\
&\to\text{稳定子商压缩}\\
&\to\text{素数阶商缺陷预算}.
\end{aligned}
\]

这是一个连贯的研究程序，而不是零散的公式堆积。

## 2.1 比值二与偶终端

令 \(L=2K\)。若存在互素除子 \(a,b\mid L\) 满足

\[
a\equiv2b\pmod R,
\]

则

\[
E=L\frac ab
\]

自然满足

\[
E\equiv2L\equiv1\pmod R.
\]

近期结果逐层补上了这一构造的三个缺口：

1. 普通密度碰撞只保证 \(D_R(L)\cap2D_R(L)\ne\varnothing\)；
2. 二进截断版本补上 \(E\) 的偶性预算；
3. 非退化与方向条件
   \[
   (a,b)\ne(1,L),(2,1),\qquad a<2b
   \]
   才保证
   \[
   1<E<2L=4K.
   \]

若 \(E\) 为偶数，得到偶终端；若 \(E\) 为奇数，只得到更小奇源的**标记下降**。所以这条路线不是单一结论，而是：

\[
\boxed{
\text{密度碰撞}
+\text{二进合法性}
+\text{高度方向}
+\text{非退化性}.
}
\]

任何后续定理都不应把这四层压成一句“除子集够大即可”。

## 2.2 线性奇—奇状态中的半块平方终端

在线性源

\[
p=a+s+asR
\]

中，若 \(a,s\) 都为奇数，令

\[
G=\frac{aR+1}{2},\qquad
H=\frac{sR+1}{2},\qquad
K=GH.
\]

一旦同一 \(R\) 已经有目标 Type I 命中，取

\[
X=\min(G,H),\qquad E=4X^2
\]

即可产生偶终端，且

\[
n=2X|a-s|<p.
\]

这条结论的重要性在于：在线性奇—奇子类中，终端搜索可被消去，难点只剩目标命中。

但它不能反推一般混合选择器，因为一般状态未必来自线性因子对，也未必是奇—奇标签。

## 2.3 Kneser 多层饱和

若

\[
K=N_1\cdots N_r,
\qquad
A_i=\mathcal A_R(N_i),
\qquad
A=A_1\cdots A_r=\mathcal A_R(K),
\]

并令

\[
T=\operatorname{Stab}_{\mathcal H_R(K)}(A),
\]

Kneser 给出

\[
|A|
\ge
\sum_i |A_iT|-(r-1)|T|.
\]

F 型状态必须满足

\[
\sum_i |A_iT|-(r-1)|T|
\le
\frac{|\mathcal H_R(K)|}{2}.
\]

严格反向不等式则强制

\[
A\cap(-A)\ne\varnothing,
\]

从而目标命中。

这是近期最重要的统一框架，因为它把：

- 两块源/仿射分解；
- 碰撞层/私有层分解；
- 多个素因子指数区间；

全部放进一个积集增长问题。

## 2.4 临界商与单活跃方向

在 F 型状态中，对稳定子商

\[
Q=\mathcal H_R(K)/T
\]

进行分析后，近期结果得到：

- \(Q\) 必须保留非平凡的阶二目标；
- \(|Q|\ge4\)；
- 当 \(|Q|=4\) 时，商中的非平凡结构极刚性；
- 在循环商 \(C_{2m}\) 的单活跃奇素因子模型中，指数预算 \(e<m\) 正是持续 F 型的条件；
- 二进方向与奇素方向共同决定目标是否进入有限矩形盒。

这组结果已经把一批 F 型障碍压缩为二维同余近似：

\[
\exists |j|\le\kappa:
\quad
\|m-\alpha j\|_{2m}\le e.
\]

它比“生成子群包含 \(-1\)”强得多，因为它精确记录了有限指数预算。

## 2.5 私有商群与稳定子商

设固定层 \(N\) 与私有素因子层分解为

\[
K=N\prod_{i=1}^k q_i^{b_i}.
\]

仓库当前版本在假设

\[
J=\mathcal C_R(N)
\]

本身是子群时，把私有中心化指数区间投影到

\[
Q=\mathcal H_R(K)/J
\]

并使用 Kneser 判断私有盒是否饱和。

最新两步进一步令

\[
B^\pm=\prod_i S_i^\pm\subseteq Q,
\qquad
T^\pm=\operatorname{Stab}_Q(B^\pm),
\]

再投影到

\[
Q/T^\pm.
\]

这一步精确保留目标成员关系，并在 \(T^\pm\ne1\) 时严格降低有限群阶。

若最终无周期商为素数阶 \(\ell\)，Cauchy–Davenport 给出：

\[
\sum_i|\overline S_i|
\ge \ell+k-1
\quad\Longrightarrow\quad
\prod_i\overline S_i=Q/T^\pm.
\]

在各方向尚未绕回的情形下，F 型必须满足显式预算：

\[
2\sum_{i\in I}b_i\le\ell-2.
\]

这是一个真正可计算的缺陷界。

# 3. 最新有限证据应如何解读

## 3.1 稠密区间审计

仓库在

\[
5\times10^8<p\le1.2\times10^9
\]

范围内记录：

\[
4\,263\,011
\]

个核心素数，其中：

\[
4\,261\,362
\]

个由普通 Type II 双尾命中，

\[
1\,649
\]

个普通 Type II 遗漏全部由 \(m\le215\) 的 Type I 偶终端闭合，未闭合数为零。

在最后区间

\[
1.1\times10^9<p\le1.2\times10^9
\]

中，核心素数数目为 599,267，普通 Type II 遗漏为 220，也全部闭合。

准确结论是：

\[
\boxed{
\text{在这些指定区间与指定搜索盒中零遗漏。}
}
\]

不能推出：

- 存在全称固定缺口界 \(m\le215\)；
- 每个素数都有线性源；
- 当前首次证书是唯一或最简单证书；
- F 型商群预算在所有状态都被统一控制。

## 3.2 平方盈余层剖面

对 1,649 张保存的首次偶终端证书，定义

\[
S=\frac{E}{\gcd(E,4K)}.
\]

仓库统计：

- \(S=1\)：63；
- 单素数幂：359；
- 至少两个不同素因子：1,227。

支持数分布为：

\[
0:63,\ 1:359,\ 2:614,\ 3:444,\ 4:149,\ 5:19,\ 6:1.
\]

在 359 个单素数幂中，指数分布为：

\[
1:319,\ 2:35,\ 3:4,\ 6:1.
\]

即使限制到 \(E<2K\) 的小侧证书，仍有大量多素数支持。

这说明：

\[
\boxed{
\text{一般终端经常需要多层指数重组，}
\quad
\text{单私有素因子路线不可能覆盖当前选择样本。}
}
\]

但由于程序保存的是**首次选中证书**，这不是“多素因子支持在该素数上不可避免”的必要性定理。建议把所有相关图表标题都明确标注：

```text
first-selected-certificate profile
```

而不是：

```text
necessary support profile
```

# 4. 当前决定性缺口

近期成果已经较好地回答了：

> 给定一个 F 型状态，如何在有限群商中识别其缺陷，并在某些局部预算条件下强制饱和？

仍未回答的是：

> 对每个普通 Type II 遗漏，为什么总能选择到一个局部预算足够好的状态？

这两者的区别可以写成：

\[
\boxed{
\text{状态内压缩}
\ne
\text{跨状态存在性}.
}
\]

更具体地，目前缺少以下任一类全称桥梁。

### 桥梁 A：状态内闭合

证明每个目标命中状态自动拥有偶终端，或每个 F 型状态经有限商压缩后必达到目标。

现有反例边界表明，这个表述可能过强：有限指数盒可以在高度接近饱和时仍遗漏目标，且终端还受二进和高度方向限制。

### 桥梁 B：跨状态重选

若某个 \((m,R,K)\) 状态失败，则构造另一个状态

\[
(m',R',K')
\]

使某个严格势函数下降，最终命中。

当前稳定子商只给出

\[
|Q/T|<|Q|,
\]

但 \(Q/T\) 未必来自另一个合法 Erdős–Straus 状态。因此它还不能作为跨状态递归。

### 桥梁 C：全局容量矛盾

假设同一素数的所有可达状态都失败，利用活跃素因子在标签差、模数差中的碰撞刚性，证明所有局部缺陷预算的总需求超过可用算术容量。

这是当前最有希望连接“局部商群理论”和“全称状态选择”的方向。

# 5. 需要立即修改的数学表述

## 5.1 把“下降”拆成两种术语

建议全仓统一：

- **quotient compression / 商群压缩**：
  \[
  Q\to Q/T,\qquad |Q/T|<|Q|;
  \]
- **arithmetic descent / 算术下降**：
  \[
  p'\!<p
  \quad\text{或一个明确良基势函数严格下降。}
  \]

当前 `stabilizer quotient descent` 之类标题容易让读者误以为已经建立对 \(p\) 的归纳。建议改为：

```text
stabilizer-quotient-compression
```

或在主张卡摘要第一句明确：

> 这里的严格下降只指有限群阶，不是源整数的递降。

## 5.2 把选择器分成三层

建议固定以下词汇：

1. **support escape / 支撑逃逸**  
   从 G 进入 F 或 hit，即证明
   \[
   -1\in\mathcal H_R(K).
   \]

2. **finite-box saturation / 有限盒饱和**  
   从 F 进入 hit，即证明
   \[
   -1\in\mathcal C_R(K).
   \]

3. **terminal orientation / 终端定向**  
   从一个恒等剩余类除子得到
   \[
   0<E<4K,
   \qquad
   E\equiv1\pmod R,
   \]
   并满足偶性和非退化条件。

这样可以防止把“角色消失”“目标命中”“得到有效偶终端”混为一谈。

## 5.3 把素数阶预算标为必要条件而非分类定理

在无周期素数阶商 \(\ell\) 中，

\[
2\sum b_i\le\ell-2
\]

是 F 型持续所需的缺陷预算。它不是充分条件：低于阈值时既可能命中，也可能继续失败。

建议主张卡明确使用：

```text
necessary obstruction budget
```

而非容易被理解为双向判据的 `classification`。

# 6. 一个应立即加入仓库的修改：去掉固定层“必须是子群”的假设

这是本轮最直接、最值得形式化的修改。

## 6.1 当前接口的限制

现有私有商群定理令

\[
J=\mathcal C_R(N)
\]

并假设 \(J\) 是子群，然后把它商掉。

但一般中心化除子谱 \(J\) 只保证：

- \(1\in J\)；
- \(J^{-1}=J\)；
- \(J\subseteq\mathcal H_R(N)\)。

它不必对乘法封闭。

如果该假设只在少量特殊状态成立，当前最强商群定理的适用范围会明显受限。

## 6.2 精确的稳定子约化

令

\[
P=\operatorname{Stab}_H(J)
=
\{h\in H:hJ=J\},
\]

其中 \(H=\mathcal H_R(K)\)。设

\[
\pi:H\to H/P.
\]

因为 \(J\) 是 \(P\)-周期集，且包含单位元，所以 \(P\subseteq J\)。若

\[
K=N\prod_{i=1}^kq_i^{b_i},
\]

则有精确投影：

\[
\boxed{
\pi(\mathcal C_R(K))
=
\pi(J)
\prod_{i=1}^k
\{\pi(q_i)^z:-b_i\le z\le b_i\}.
}
\]

而且 \(\pi(J)\) 在 \(H/P\) 中是无周期集。

由于整个乘积集是 \(P\)-周期的，目标成员关系精确保留：

\[
-1\in\mathcal C_R(K)
\iff
\pi(-1)\in
\pi(J)\prod_i S_i^\pm.
\]

这条约化不再让固定层“消失”，而是把它变成一个无周期固定缺陷因子

\[
J_0=\pi(J).
\]

随后可以直接对

\[
J_0S_1^\pm\cdots S_k^\pm
\]

应用多集合 Kneser、Kemperman 逆结构或 Pollard 型表示数定理。

## 6.3 建议的新主张卡

```text
type-I-fixed-layer-stabilizer-defect-reduction
```

建议状态：

```yaml
claim_status: established
proof_provenance: repository_derivation
review_status: internal_review
```

并附独立小群穷举 verifier。

这条修改比继续在“\(J\) 为子群”的特例上增加更多推论更有价值，因为它扩大了整个私有商群程序的自然适用域。

# 9. 下一阶段研究计划

## 9.1 第一阶段：两周内完成的工作

### A. 形式化固定层稳定子缺陷约化

这是最直接的理论增量。完成后统计：

\[
\Pr[J\text{ 是子群}],
\qquad
|P|,
\qquad
|\pi(J)|,
\qquad
\text{固定层缺陷大小}.
\]

若 \(J\) 很少为子群，说明该修改是必要的；若经常为子群，则现有接口获得数据支持。

### B. 对当前困难 F 状态计算完整商群链

对每个状态记录：

\[
H\to H/T_1\to(H/T_1)/T_2\to\cdots
\]

以及每一步：

- 群阶；
- 不变量分解；
- Kneser 缺陷；
- 是否达到素数阶；
- 剩余活跃方向数；
- 目标是否命中。

目标不是声称递降证明，而是识别“商群压缩的终端正常形”。

### C. 审计比值二之外的 \(2^j\) 传输

第二份报告给出一个可直接证明的推广。应优先运行：

\[
D_R(L)\cap2^jD_R(L)
\]

对所有二进预算合法的 \(j\)，统计它比 \(j=1\) 多闭合多少状态。

## 9.2 第二阶段：三至六周

### A. 目标表示纤维审计

不要只记录 \(-1\) 是否出现。记录全部指数表示

\[
\mathcal Z^-_{R,K}
=
\left\{
z:
|z_i|\le\nu_i,\
\prod q_i^{z_i}\equiv-1\pmod R
\right\}.
\]

重点统计：

\[
|\mathcal Z^-_{R,K}|,
\]

以及任意两表示的加权坐标距离。

若目标有大量不同表示，可能自动生成偶终端；若表示极少，则应出现强逆结构。

### B. 傅里叶与格对偶证书

对每个 G/F 状态计算：

- 最大非平凡傅里叶系数；
- 对应字符阶；
- 被该字符近似固定的素因子预算；
- 关系格的最短加权对偶向量。

目标是检验：

\[
\boxed{
\text{F 型是否总伴随低复杂度近角色或小预算方向？}
}
\]

### C. 跨状态全局容量

对重复活跃素因子 \(q\)，按幂次 \(q^h\) 分层统计其可出现状态。利用：

\[
q^h\mid \text{标签差或模数差}
\]

给出全局碰撞容量，再与所有失败状态所需的活跃预算比较。

## 9.3 第三阶段：六至十周

尝试证明一个真正连接局部与全局的二分定理：

\[
\boxed{
\begin{array}{l}
\text{某个状态的目标表示纤维丰富}
\Rightarrow
\text{同状态偶终端};\\[1mm]
\text{所有状态的目标纤维稀疏}
\Rightarrow
\text{低秩/短角色结构};\\[1mm]
\text{这些结构跨全部状态不可能同时满足}
\Rightarrow
\text{存在命中状态}.
\end{array}}
\]

这比试图直接证明“所有 F 型盒最终饱和”更符合现有反例边界。

# 11. 当前最佳研究定位

项目现在已经从“单位分数恒等式搜索”进入了更明确的数学问题：

\[
\boxed{
\text{有限阿贝尔群中带有算术来源的有界指数盒，
何时必含指定的阶二目标？}
}
\]

近期结果提供了三层工具：

\[
\boxed{
\begin{array}{c}
\text{Kneser：积集增长}\\
\text{稳定子商：周期压缩}\\
\text{素数阶预算：显式缺陷}
\end{array}}
\]

但完整证明还缺少第四层：

\[
\boxed{
\text{算术状态选择或跨状态容量矛盾。}
}
\]

因此最准确的下一阶段目标不是“继续完善某个固定状态的群论”，而是：

> 把每个失败状态压缩得到的低复杂度缺陷证书，拉回到标签、模数、素因子幂和源距离上；证明同一素数的全部可达状态不能同时承载这些证书。

第二份报告给出了几条可执行的跨领域路线，其中最优先的三个突破点是：

1. 固定层稳定子缺陷约化；
2. 目标表示纤维近邻产生偶终端；
3. 傅里叶/格对偶低复杂度证书与跨状态碰撞容量的结合。
