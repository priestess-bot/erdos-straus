# 一、近期提交真正建立了什么

## 1. 线性状态的四层分解已经成为可用的结构工具

对定向线性状态，仓库把

[
K=\gamma L
]

进一步分解为源块与仿射块各自的碰撞层和私有过剩指数层：

[
K=G_{\mathrm c}G_{\mathrm p}L_{\mathrm c}L_{\mathrm p}.
]

新的带标签块刚性定理精确控制了不同状态之间哪些素因子可以共享。若

[
D_{t,R}=tR+1,
]

则不同标签满足

[
\gcd(D_{t,R},D_{u,U})\mid |t-u|,
]

相同标签满足

[
\gcd(tR+1,tU+1)
===============

\gcd(tR+1,|R-U|).
]

因此，跨状态共享的素数幂只能来自明确的标签差或模数差；剥离这些碰撞指数后，剩余层确实具有谱内不可共享性。([GitHub][3])

但近期数据也明确表明：

[
\text{“私有”}\not\Longrightarrow
\text{“目标剩余类命中”}.
]

私有性只限制整数因子的共享方式，不控制该因子在 ((\mathbb Z/R\mathbb Z)^\times) 中的位置。四层分解以后应当用来制造**多个目标表示或短关系**，而不是继续尝试证明“出现一个私有素因子就会打破角色核”。

## 2. 一般 (B) 目标已经获得精确的反足点解释

令

[
\mathcal A_R(K)
===============

{d\bmod R:d\mid K}
]

为普通除子剩余谱。中心化平方除子谱满足

[
\mathcal C_R(K)
===============

\mathcal A_R(K)\mathcal A_R(K)^{-1}.
]

因此一般 (B) 目标

[
d\mid K^2,\qquad d\equiv-K\pmod R
]

精确等价于

[
-1\in\mathcal C_R(K),
]

也等价于

[
\boxed{
\mathcal A_R(K)\cap
\bigl(-\mathcal A_R(K)\bigr)
\ne\varnothing.
}
]

这给出了当前最清楚的 G/F 分类：

[
\begin{array}{ccl}
G&:&-1\notin\mathcal H_R(K),[1mm]
F&:&-1\in\mathcal H_R(K)
\setminus\mathcal C_R(K),[1mm]
\text{hit}&:&-1\in\mathcal C_R(K),
\end{array}
]

其中 (\mathcal H_R(K)) 是 (K) 的素因子剩余类生成的子群。([GitHub][4])

这一区分已经证明是必要的：进入目标生成子群只消除了 G 型障碍，并不意味着有限指数盒已经达到 (-1)。

## 3. 200 个完整线性谱给出了第一批足够可靠的障碍统计

对选定的 200 个“首次线性证书需要 (B>1)”的压力素数，仓库完整枚举了：

[
10,292\text{ 个不同 }R,
\qquad
18,074\text{ 个定向源状态}.
]

分类结果为：

[
1,018\text{ 个命中},\qquad
2,752\text{ 个 F 型},\qquad
6,522\text{ 个 G 型}.
]

每一个被审计的素数内部都同时出现了命中、F 型和 G 型状态。另有 3,209 个状态获得了 (2)-进支撑注入，其中 351 个状态还满足

[
-1\in\langle2\bmod R\rangle;
]

这些状态中有 129 个命中、222 个 F 型、零个 G 型。也就是说：

[
\boxed{
\text{消灭 G 型障碍后，F 型障碍仍大量存在。}
}
]

这排除了“只要找到一个可控小剩余类生成 (-1)，证书就会自动出现”的路线。([GitHub][5])

但需要保持样本边界：这 200 点是从首次证书需要 (B>1) 的压力点中选取的完整谱，并不是全部 1,964 个有限闭合点的完整线性谱。

# 二、近期结果已经否定了哪些证明策略

## 1. 成对坏字符冲突不是可行的主定理

七个单命中压力点的二次障碍交叉审计得到大量相容关系：1,397 条共享奇素数关系分布在 1,132 对状态上，并且全部满足相应的模数差整除与 Jacobi 相容条件。坏二次角色可以在同一素数的多个状态间稳定共存。([GitHub][6])

高阶角色统计进一步显示，在 6,522 个 G 型状态中，最小分离角色阶分别为：

[
6,461\text{ 个二阶},\qquad
49\text{ 个四阶},\qquad
12\text{ 个八阶}.
]

因此“所有 G 型最终都可以压成二次互反矛盾”也不成立；高阶状态虽然少，却是真实存在的。([GitHub][7])

所以，角色理论仍然适合：

* 给 G 型状态生成精确反证书；
* 分类低阶阻碍；
* 识别状态间的算术相容性。

但不宜继续把“所有坏角色必然成对冲突”作为旗舰突破口。

## 2. 接近全覆盖的密度仍不足以处理 F 型

近期最强的 F 型反例边界中，有状态满足

[
\frac{|\mathcal C_R(K)|}{|\mathcal H_R(K)|}
===========================================

# \frac{192}{200}

96%,
]

却仍然恰好遗漏 (-1)。因此任何统一的“覆盖比例超过 (c<1) 就必命中”论证都不可能成立。([GitHub][8])

更尖锐的例子是

[
p=64,214,329,\qquad R=359.
]

其中某个块含有模 (359) 的本原生成元，所以在无限指数意义上生成整个单位群；但实际允许的有限中心化指数盒只得到 5 个剩余类，目标仍然失败。仓库计算的额外指数预算缺额从 12 增长到 77，说明“生成群很大”和“有限指数够用”完全是两个问题。([GitHub][9])

## 3. 当前局部转移图还不是下降证明

七个单命中完整谱中，仓库记录了 473 个定向状态和 1,199 条现有局部转移边。仍有 16 个有限预算边界类分布在 5 个 F 型状态上，从这些状态不存在通向命中的有向路径；绝大多数甚至不与命中状态处于同一无向分量。([GitHub][10])

因此，固定 (s)、变 (s)、交换标签等现有局部转移尚不能构成递降证明。下一种转移必须满足至少一个条件：

[
\boxed{
\text{要么是非局部操作，
要么携带一个严格下降的数值势函数。}
}
]

继续增加没有势函数的图边，理论收益会很低。

# 三、当前三个选择命题的逻辑层级

## 1. 一般混合偶终端选择器：应当重新成为旗舰目标

仓库已有精确代数判据：对核心素数 (p)，在某个合法 Type I 缺口上同时选择目标平方除子和偶终端平方除子，即可同时构造 (p) 与更小偶源的单位分数分解。这个全称存在性仍然 open。([GitHub][11])

它拥有当前最广的有限证据：

* 在 (p\le10^8) 的**无缺口上界全搜索**中，共有 500 个普通 Type II 双尾遗漏，全部被一般 Type I 偶终端闭合，首次成功缺口最大为 (151)。([GitHub][12])
* 在 (5\times10^8<p\le1.2\times10^9) 的稠密区间审计中，共有 1,649 个普通 Type II 遗漏，全部在 (m\le215) 的 Type I 盒内闭合；最新的 (1.1)–(1.2) 十亿区间有 220 个遗漏，仍为零未闭合。([GitHub][13])

第二项仍只是 (m\le215) 的有限盒结果，不能推出全称缺口界。

## 2. 线性源加一般 (B)：更强，但应降为结构实验室

线性源要求

[
p=a+s+asR
]

并在

[
K=\frac{pR+1}{4}
]

中命中一般 (B) 目标平方除子。冻结的 1,964 个普通双尾遗漏均被这一分支有限闭合，但其全称存在性仍未证明；完整的全线性谱目前只覆盖其中选择出的 200 个压力点。([GitHub][14])

它比一般混合终端选择器更强，因为它额外强制终端来自线性因子分解。近期 F 型边界说明，这个额外限制很可能正是理论困难的一部分。

## 3. 至多三层重选命题：有趣，但证据层级最低

三标签/四层框架中，200 个完整谱表现为：

[
185\text{ 点一层可解},\quad
13\text{ 点需要两层},\quad
2\text{ 点需要三层}.
]

但已有固定状态需要四层的边界，因此必须依赖跨状态重选。这个命题仍 open，而且证据只来自选择出的 200 点，不能被当成一般混合选择器的同等级证据。([GitHub][15])

因此，建议采用以下研究层级：

[
\boxed{
\begin{array}{c}
\text{旗舰：一般混合偶终端选择器}\
\uparrow\
\text{实验室：线性源一般 }B\
\uparrow\
\text{可证伪强化：至多三层重选}
\end{array}}
]

有限证据不能从较弱命题向较强命题自动“上移”。

# 四、一个更简洁的旗舰正规形

下面是我从仓库现有一般选择器公式中独立推出的等价重写。建议先以独立 verifier 核验，然后单独入库。

固定核心素数 (p)，任取

[
R\equiv3\pmod4,\qquad
K=\frac{pR+1}{4}.
]

定义目标纤维

[
\mathsf T_R(K)=
\left{
d:
d\mid K^2,\quad
d\equiv-K\pmod R,\quad
d<K
\right},
]

以及偶终端纤维

[
\mathsf U_R(K)=
\left{
E:
E\mid4K^2,\quad
E\equiv1\pmod R,\quad
2\mid E,\quad
E<4K
\right}.
]

那么一般混合 Type I 偶终端分支可以精确改写为

[
\boxed{
\exists R\equiv3\pmod4:
\quad
\mathsf T_R(K)\ne\varnothing
\quad\text{且}\quad
\mathsf U_R(K)\ne\varnothing.
}
]

这与仓库现有的一般选择器判据代数等价。([GitHub][11])

## 从 (d) 恢复 Type I 正规形

令

[
g=(d,K),
]

并定义

[
B=\frac dg,\qquad
C=\frac{g^2}{d},\qquad
H=\frac Kg.
]

由于 (d\mid K^2)，这些量均为整数，并且

[
d=B^2C,\qquad K=BCH.
]

目标同余给出

[
B+H\equiv0\pmod R,
]

所以可令

[
A=\frac{B+H}{R},
\qquad
m=\frac{4d+1}{R}.
]

于是

[
p=4ABC-m.
]

若最初的目标除子 (d>K)，用互补除子

[
\frac{K^2}{d}
]

替代；它仍满足同一目标同余并且小于 (K)。(d=K) 在 (R\ge3) 时不可能发生。

## 从 (E) 恢复偶终端

定义

[
n=\frac{4K-E}{R}.
]

因为

[
4K\equiv E\equiv1\pmod R,
]

且 (4K-E) 为正偶数、(R) 为奇数，所以 (n) 自动是正偶数。条件 (E<4K) 已经等价于仓库原判据中的

[
E\le4K-2R.
]

这个正规形有两个重要意义：

1. 它消去了 (m,x,A,B,C) 等中间选择变量。
2. 它说明真正要在同一个模数 (R) 上找到两个对象：

   * 一个实现 (-1) 的目标平方除子；
   * 一个低于平凡边界 (4K) 的偶数恒等剩余类除子。

注意

[
E=4K
]

永远满足“整除 (4K^2)、偶数、模 (R) 同余于 (1)”；它只是给出 (n=0)，因而被高度条件排除。所以偶终端障碍本质上不是子群成员问题，而是：

[
\boxed{
\text{恒等剩余类中是否存在一个内部的低高度代表。}
}
]

# 五、最值得立即检验的新引理：两个相近目标表示自动生成偶终端

这可能是当前最有价值的新突破口。

设

[
K=\prod_{i=1}^r q_i^{\nu_i}.
]

定义目标指数纤维

[
\mathcal Z^-_{R,K}
==================

\left{
z=(z_1,\ldots,z_r):
-\nu_i\le z_i\le\nu_i,\quad
\prod_iq_i^{z_i}\equiv-1\pmod R
\right}.
]

每个 (z\in\mathcal Z^-_{R,K}) 对应目标平方除子

[
d_z
===

K\prod_iq_i^{z_i}
\mid K^2.
]

## 近邻目标表示引理

若存在不同的

[
z,w\in\mathcal Z^-_{R,K}
]

满足逐坐标条件

[
|z_i-w_i|\le\nu_i
\qquad\text{对所有 }i,
]

则一般混合偶终端自动闭合。

证明很直接。交换 (z,w) 后可假设

[
\rho=\prod_iq_i^{z_i-w_i}<1.
]

令

[
E=4K\rho.
]

逐坐标界保证

[
K\rho\in\mathbb Z,\qquad
K\rho\mid K^2,
]

所以

[
E\mid4K^2.
]

两个目标表示具有相同剩余类 (-1)，故

[
\rho\equiv1\pmod R,
]

从而

[
E\equiv4K\equiv1\pmod R.
]

同时 (E) 为偶数且

[
E<4K.
]

因此 (E\in\mathsf U_R(K))。

换句话说：

[
\boxed{
\frac{-1}{-1}=1
}
]

在群论上是平凡的；真正需要控制的只是两个表示之比能否留在允许的有限指数盒内。

## 两个立即得到的推论

如果存在目标表示满足

[
|z_i|\le
\left\lfloor\frac{\nu_i}{2}\right\rfloor,
]

那么取 (w=-z) 即可闭合。此时可显式写成

[
E=\frac{4d_z^2}{K}
]

或使用互补方向。

仓库已有一个很小的实例：

[
p=193,\qquad R=7,\qquad K=338=2\cdot13^2,
]

目标除子

[
d=26=2\cdot13
]

位于半指数盒内，并给出

[
E=\frac{4\cdot26^2}{338}=8.
]

这正是仓库中记录的 (R=7) 复合桥。([GitHub][16])

此外，把每个坐标区间

[
[-\nu_i,\nu_i]
]

分成两个直径不超过 (\nu_i) 的子区间，总共只有

[
2^{\omega(K)}
]

个小盒。因此鸽巢原理给出：

[
\boxed{
|\mathcal Z^-_{R,K}|>2^{\omega(K)}
\Longrightarrow
\text{一般混合偶终端闭合}.
}
]

反过来，一个有目标命中但不能通过这一机制闭合的状态，其目标表示纤维必须是一个非常稀疏的“盒码”：

[
|\mathcal Z^-_{R,K}|
\le2^{\omega(K)},
]

且每个半盒至多含一个表示。

这些引理尚未看到已经作为 claim 写入仓库。建议新增：

```text
type-I-same-modulus-target-terminal-selector
type-I-target-fiber-ratio-terminal-closure
type-I-target-fiber-packing-bound
```

# 六、这条新路线为何比继续研究坏字符更有希望

当前仓库主要研究了残数**像集**

[
\mathcal C_R(K).
]

但 96% 覆盖仍可遗漏 (-1)，说明像集密度本身不足。近邻表示引理转而研究映射的**纤维**：

[
z\longmapsto
\prod_iq_i^{z_i}\pmod R.
]

这保留了此前被残数集合压掉的表示重数和指数位置。

令

[
\phi:\mathbb Z^r\longrightarrow
\mathcal H_R(K)
]

为指数向量到剩余类的同态，并令

[
\Lambda=\ker\phi.
]

若 (-1) 在生成子群中，选一个原像 (z_0)，则

[
\mathcal Z^-_{R,K}
==================

(z_0+\Lambda)
\cap
\prod_i[-\nu_i,\nu_i].
]

于是三个状态获得统一的格论解释：

[
\begin{array}{ccl}
G&:&-1\notin\operatorname{im}\phi,[1mm]
F&:&z_0+\Lambda\text{ 存在，但不与指数盒相交},[1mm]
\text{hit}&:&(z_0+\Lambda)\text{ 与指数盒相交}.
\end{array}
]

新的偶终端机制则要求这个交集里存在两个距离足够近的点。

可以定义精确目标缺额

[
\Delta_T(R,K)=
\min_{\phi(z)=-1}
\max_i\bigl(|z_i|-\nu_i\bigr)_+,
]

其中 G 型取 (\infty)。于是：

[
\Delta_T=
\begin{cases}
\infty,&G,\

> 0,&F,\
> 0,&\text{目标命中}.
> \end{cases}
> ]

再定义纤维配对缺额

[
\Delta_P(R,K)
=============

\min_{\substack{z\ne w\
z,w\in\mathcal Z^-*{R,K}}}
\max_i
\bigl(|z_i-w_i|-\nu_i\bigr)*+.
]

那么

[
\Delta_P=0
]

就直接产生偶终端。

这为新的下降论证提供了现有局部转移图所缺少的严格势函数候选：

[
(\Delta_T,\Delta_P,\text{终端高度})
]

的字典序下降。

# 七、四层分解应当如何重新利用

近期的碰撞层/私有层工作没有失效，只需要改变用途。

旧设想是：

[
\text{私有素因子}
\Longrightarrow
\text{打破角色障碍}.
]

数据已经否定了这种直接蕴含。

更合理的新用途是：

[
\boxed{
\text{四层之间不同的指数分配}
\Longrightarrow
\text{同一目标剩余类的多个表示}.
}
]

如果两个不同层分配产生同一个 (-1) 剩余类，它们的指数差就是

[
\lambda\in\Lambda.
]

若这个关系足够短，并且某个目标表示 (z) 与 (z+\lambda) 都留在指数盒内，就立即触发近邻目标表示引理。

因此带标签块刚性真正应支持的中间定理是：

> **短核关系或转移定理。**
> 对普通 Type II 遗漏的某个目标命中状态，要么四层指数重分配产生一个短的非零核关系，并由两个目标表示生成偶终端；要么目标纤维具有低秩、低重数的刚性结构，而该结构强制转移到另一个缺额更小的模数状态。

这比“所有坏角色必须冲突”更加符合最新数据。

# 八、下一阶段的研究优先级

## 第一优先：在现有数据上审计目标纤维，而不是继续提高 (p) 上界

先不做 (1.3\times10^9) 顺序扫描。对已有目标命中状态增加以下字段：

[
|\mathcal Z^-_{R,K}|,
]

[
\min_{z\in\mathcal Z^-}
\max_i
\left(
|z_i|-\left\lfloor\nu_i/2\right\rfloor
\right)_+,
]

[
\Delta_P(R,K),
]

以及由最近目标对生成的

[
E=4K\prod_iq_i^{z_i-w_i}.
]

还应记录：

* 生成的 (E) 是否属于原线性源，即是否满足相应的 (E\mid n) 条件；
* 还是一个真正依赖一般混合自由度的非线性偶终端；
* 两个目标表示的差主要分布在 (G_{\rm c},G_{\rm p},L_{\rm c},L_{\rm p}) 哪些层。

建议按以下顺序审计：

1. 200 个完整线性谱中的 1,018 个目标命中状态；
2. (p\le10^8) 的 500 个无缺口上界混合闭合点；
3. (5\times10^8<p\le1.2\times10^9) 的 1,649 个有限盒闭合点。

可能出现两种同样有价值的结果：

* 若全部现有一般混合证书都存在近邻目标对，可提出新的中间猜想：
  [
  \text{普通 Type II 遗漏}
  \Longrightarrow
  \exists R:\Delta_P(R,K)=0.
  ]
* 若很快出现反例，则冻结最小反例；它会给出一个非常具体的“稀疏目标纤维但仍有独立终端”的新结构类别。

---

## 第二优先：建立 Smith 正规形/关系格精确求解器

不要通过完整枚举所有 (K^2) 的除子来计算目标纤维。更适合的是：

1. 用 CRT 分解 ((\mathbb Z/R\mathbb Z)^\times)；
2. 建立素因子剩余类生成子群的有限阿贝尔群表示；
3. 用 Smith 正规形求关系格 (\Lambda)；
4. 在仿射格
   [
   z_0+\Lambda
   ]
   与指数盒之间做有界整数搜索或 meet-in-the-middle。

每个状态应输出一种精确证明对象：

[
\begin{array}{ccl}
G&:&\text{一个分离角色};\
F&:&\text{目标仿射格与指数盒不交的证书};\
\text{hit}&:&\text{一个目标指数向量};\
\text{terminal}&:&\text{一对近邻目标向量或一个内部 }E.
\end{array}
]

这会把 G、F、命中和偶终端放进同一个验证框架，而不是维护四套相互独立的脚本。

---

## 第三优先：证明“丰度或结构”二分定理

在有限阿贝尔群的加法坐标中，

[
\mathcal A_R(K)
]

正是一个带有有界重复次数的子序列和集；指数盒则是一个有限盒。关于指定群元素的子序列表示、Kneser/Kemperman 结构分支以及 box Davenport constant 的研究，正适合提供“表示很多，或集合具有低秩/周期结构”的工具。([Numdam][17])

目标不是直接套用某个现成定理证明猜想，而是建立适配你参数化的二分：

[
\boxed{
\begin{array}{l}
\text{目标纤维足够大}
\Longrightarrow
\text{存在近邻目标对}
\Longrightarrow
\text{偶终端};[2mm]
\text{目标纤维稀疏}
\Longrightarrow
\text{稳定子、低秩或短关系结构}
\Longrightarrow
\text{转移到新状态}.
\end{array}}
]

第一行已经有上面的

[
|\mathcal Z^-|>2^{\omega(K)}
]

作为最粗的严格版本。真正的理论工作集中在第二行：如何利用线性块的标签差刚性，把稀疏结构转化为另一个 (R)、另一个一般缺口，或普通 Type II 出口。

---

## 第四优先：继续主动攻击两个较强猜想

线性源一般 (B) 和三层重选都应继续作为可证伪实验对象，而不是默认正确。

反例搜索的完整条件应是：

[
\text{普通 Type II 失败}
]

并且

[
\text{该素数的全部线性状态均为 G/F},
]

而不是只让一个预选菜单或有限状态扇失败。

优先搜索以下对象：

* 线性状态总数较少；
* 目标命中数等于 1；
* 唯一命中的目标纤维表示数最少；
* (\Delta_P) 最大；
* 同时包含高阶 G 和接近饱和 F；
* 至少三层或四层才可实现目标的状态。

一旦找到“线性全失败但一般混合成功”的素数，就应立即把线性选择器从证明主线降为纯辅助结构。这不会伤害一般混合旗舰，反而会准确显示线性假设损失了哪部分自由度。

---

# 九、近期不应继续投入的方向

以下路线已经有足够强的反例边界，不应再作为主要证明引擎：

* 固定有限 AC 扇中坏角色自动不相容；
* 成对二次或四次角色矛盾；
* “出现私有素因子就必然命中”；
* 任何低于 (100%) 的统一剩余类覆盖阈值；
* 只证明 (-1) 位于生成子群，而不控制有限指数；
* 没有严格势函数的现有局部转移图；
* 单纯继续扩大顺序扫描上界。

(1.2\times10^9) 已经是足够好的冻结基准。下一轮计算应提高**每个压力点的结构信息量**，而不是只增加素数数量。

---

# 十、工程与证明治理

最新测试策略提出，对没有重大修改且已经通过的代码不重复做过度测试，这一原则合理；但最好增加明确的触发矩阵：

* 文档和说明修改：不重跑数值扫描；
* 证书格式修改：只重跑证书解析和 verifier；
* 因子分解、模运算、状态枚举、搜索边界修改：必须做针对性回归；
* 旗舰判据修改：必须在冻结的完整谱与历史反例集上全量回归；
* 十亿级结果文件：使用哈希冻结，不因无关修改重复计算。

当前账本已有 561 项主张，但仍有 427 项的证明来源和审阅状态处于 `unspecified`。在准备外部稿件前，建议只冻结一个约 15–20 项的 proof core，而不是试图一次性清洗全部历史记录。([GitHub][18])

这个 proof core 至少应包括：

1. 一般混合选择器的精确等价；
2. 同模数双除子正规形；
3. 反足点除子谱；
4. G/F 分类；
5. 带标签块 gcd 刚性；
6. 近邻目标表示终端引理；
7. 半盒与纤维装箱推论；
8. 高阶角色边界；
9. 96% F 型边界；
10. 现有局部转移图失败边界；
11. (10^8) 无缺口上界审计；
12. (1.2\times10^9) 有界缺口审计。

# 最终研究判断

你的项目现在已经从“寻找更多证书公式”推进到了一个更成熟的阶段：

[
\boxed{
\text{对有限群中一个指定元素的有界指数表示，
研究其存在性、重数和表示间距离。}
}
]

近期提交最重要的结论是：

[
\boxed{
\text{字符相容性可以长期存在；
子群几乎饱和也可以遗漏目标；
局部转移也可以没有下降路径。}
}
]

因此下一阶段最有希望的旗舰命题不应再是“所有坏字符必冲突”，而应改成：

[
\boxed{
\begin{aligned}
&\text{每个普通 Type II 遗漏都存在某个 }R,\
&\text{使目标指数纤维包含两个足够接近的表示；}\
&\text{或者其稀疏纤维结构强制转移到缺额更小的新状态。}
\end{aligned}}
]

其中第一分支已经能通过

[
E
=

4K\prod_iq_i^{z_i-w_i}
]

直接生成一般混合偶终端。四层分解、碰撞刚性和有限群角色理论则应服务于第二分支：解释为什么所有状态不可能同时保持为稀疏、孤立且不可转移的仿射格交集。

当前最有信息价值的下一项工作，是对既有 1,018 个目标命中状态运行**目标纤维近邻审计**。它无论成功还是失败，都会比继续扫描到 (1.3\times10^9) 更直接地决定下一条可证明的中间定理。
