# 一、三项新增理论结论核查

## 1. 回缩判据完全正确

令

[

]

由

[
K=\frac{pR+1}{4}=kp-B_p
]

立即得到

[
k\mid K\iff k\mid B_p.
]

对任意当前选择的桥因子和源，

[
4K=nR+E.
]

模 (R+1) 有 (R\equiv-1)，所以

[
4K\equiv E-n\pmod{R+1}.
]

因为 (R+1=4k)，于是

[
\boxed{
k\mid K
\iff
E\equiv n\pmod{R+1}.
}
]

这也准确说明了为什么 (E\mid n) 仍不充分：它没有强制 (E-n) 被 (R+1) 整除。仓库在选定的 1,717 张证书中记录了 62 张 (E\mid n) 但不能回缩的例子，这个分类是有实际内容的。

[

桥存在的精确条件是

[

]

同一正规形回缩到线性外源的条件则是

[
r\mid t.
]

你构造的射线令

[

]

所以 (r\mid t^2) 而 (r\nmid t)，缺额为任意给定的 (a)。Dirichlet 进程的原始性、(p\equiv1\pmod{24})、以及同缺口 Type II 失败的模 (5) 条件也相互一致。

# 三、把二层选择再消去两个伪自由变量

仓库的源优先等价式是

[
\begin{aligned}
&s\text{ 为奇数},\quad n=p-s,\
&R\equiv3\pmod4,\quad

&E\mid\frac{n^2}{\gcd(E,4)},\
&C\mid K,\quad 4C\equiv-1\pmod R.
\end{aligned}

([GitHub][3])

定义

[
\lambda(s)=
\begin{cases}
4,&s\equiv1\pmod4,\
2,&s\equiv3\pmod4.
\end{cases}
]

因为 (p\equiv1\pmod4)、(R\equiv3\pmod4)，自动有

[
\lambda=\gcd(n,4)=\gcd(E,4).

再令

[
u=\frac{p-s}{\lambda},\qquad
D=\frac{E}{\lambda}.
]

则第一层精确化为

[
\boxed{
D\mid u^2,\qquad
\lambda D\equiv1\pmod s,\qquad
R=\frac{\lambda D-1}{s}.
}
]

所以 (E) 和 (R) 并不是独立变量：

[
E=\lambda D,\qquad R=\frac{\lambda D-1}{s}.
]

目标侧令

[
H=\frac KC.
]

由 (4K\equiv1\pmod R) 可得

[
C\mid K,\quad4C\equiv-1\pmod R
\iff
H\mid K,\quad H\equiv-1\pmod R.
]

所以 (C) 也不是独立变量：

[
C=\frac KH.
]

因此真正的选择自由度只有：

[
\boxed{\text{源侧 }(s,D)\quad+\quad\text{目标侧除子 }H.}

条件 (D\mid u^2) 有唯一的正规分解

\gamma=\frac g\beta,\qquad
\alpha=\frac ug.

[
\eta=\frac4\lambda\in{1,2}.

[

这说明第一层并不是先生成一个与目标层无关的整数 (K)。它自动给 (K) 提供了一个显式因子块
