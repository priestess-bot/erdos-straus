# 0. 核心观点

当前问题可以统一写成一个**带算术来源的有限群盒命中问题**。

令

\[
K=\prod_{i=1}^r q_i^{\nu_i},
\qquad
H=\mathcal H_R(K)
=
\langle q_i\bmod R\rangle,
\]

并定义同态

\[
\phi:\mathbb Z^r\longrightarrow H,
\qquad
\phi(z_1,\ldots,z_r)
=
\prod_{i=1}^r q_i^{z_i}\pmod R.
\]

指数盒为

\[
B_\nu=
\prod_{i=1}^r[-\nu_i,\nu_i]\cap\mathbb Z^r.
\]

目标 Type I 命中等价于

\[
-1\in\phi(B_\nu).
\]

因此：

- G 型：
  \[
  -1\notin\operatorname{im}\phi;
  \]
- F 型：
  \[
  -1\in\operatorname{im}\phi
  \quad\text{但}\quad
  \phi^{-1}(-1)\cap B_\nu=\varnothing;
  \]
- hit：
  \[
  \phi^{-1}(-1)\cap B_\nu\ne\varnothing.
  \]

这已经同时连接到：

1. 有限阿贝尔群加法组合学；
2. 格与几何数论；
3. 有限傅里叶分析和随机游走；
4. 逆 Littlewood–Offord 理论；
5. 编码与装箱；
6. \(p\)-进碰撞和算术组合几何。

本报告提出的总策略是一个三分法：

\[
\boxed{
\begin{array}{ll}
\text{目标表示很多}
&\Rightarrow\text{两个近邻表示}\Rightarrow\text{偶终端};\\[1mm]
\text{目标表示很少}
&\Rightarrow\text{逆加法结构或短对偶角色};\\[1mm]
\text{目标没有表示}
&\Rightarrow\text{精确/近似角色障碍，再做跨状态容量矛盾}.
\end{array}}
\]

这比单纯追求“除子剩余类覆盖率接近 100%”保留了更多信息：它研究的是**指定目标的表示纤维**，而不只是像集。

# 1. 突破点一：固定层稳定子缺陷约化

## 1.1 动机

现有私有商群定理通常写成

\[
K=N\prod_{i=1}^kq_i^{b_i},
\]

把固定层

\[
J=\mathcal C_R(N)
\]

作为子群商掉。但一般 \(J\) 不必是子群。它只是一个包含单位元的对称有限集。

这并不意味着商群路线失效；正确做法是先商掉 \(J\) 的稳定子，而不是假设 \(J\) 自身为群。

## 1.2 可立即证明的新引理

令

\[
H=\mathcal H_R(K),
\qquad
J=\mathcal C_R(N)\subseteq H,
\]

并令

\[
P=\operatorname{Stab}_H(J)
=
\{h\in H:hJ=J\}.
\]

设

\[
\pi:H\to H/P.
\]

若 \(q_i\) 是固定层外的不同素因子，定义

\[
S_i^\pm
=
\{q_i^z:-b_i\le z\le b_i\}.
\]

则有：

\[
\boxed{
\pi(\mathcal C_R(K))
=
\pi(J)\prod_{i=1}^k\pi(S_i^\pm).
}
\]

而且：

1. \(P\subseteq J\)；
2. \(\pi(J)\) 在 \(H/P\) 中无周期；
3. 目标成员关系精确保留：
   \[
   -1\in\mathcal C_R(K)
   \iff
   \pi(-1)\in
   \pi(J)\prod_i\pi(S_i^\pm).
   \]

### 证明

因为 \(1\in J\)，若 \(p\in P\)，则

\[
p=p\cdot1\in pJ=J,
\]

故 \(P\subseteq J\)。

又因为

\[
\mathcal C_R(K)=J\prod_iS_i^\pm,
\]

投影后得到第一式。

若 \(xP\) 稳定 \(\pi(J)\)，则

\[
xJP=JP.
\]

但 \(JP=J\)，故 \(xJ=J\)，于是 \(x\in P\)。所以 \(\pi(J)\) 无周期。

最后，\(J\prod_iS_i^\pm\) 是 \(P\)-周期集，因此一个元素是否属于该集合完全由其 \(H/P\) 像决定。

## 1.3 为什么这是重要修改

这条引理把现有程序从

\[
\text{固定层恰好是子群}
\]

推广到

\[
\text{任意固定中心化谱}.
\]

固定层不会完全消失，而是变成无周期缺陷因子

\[
J_0=\pi(J).
\]

真正需要研究的是

\[
J_0S_1^\pm\cdots S_k^\pm.
\]

这正适合：

- Kneser 增长；
- Kemperman 临界结构；
- Pollard 表示数；
- 多层逆加法定理。

## 1.4 建议仓库主张

```text
type-I-fixed-layer-stabilizer-defect-reduction
```

建议把它作为当前 `type-I-private-quotient-box-saturation` 的前置一般化，而不是旁支。

# 2. 突破点二：目标表示纤维的近邻对自动产生偶终端

这是本报告中最直接、最可能立即转化为新证书选择器的结果。

## 2.1 目标表示纤维

定义

\[
\mathcal Z^-_{R,K}
=
\left\{
z\in B_\nu:
\prod_{i=1}^r q_i^{z_i}\equiv-1\pmod R
\right\}.
\]

每个 \(z\in\mathcal Z^-_{R,K}\) 对应一个目标平方除子：

\[
d_z
=
K\prod_iq_i^{z_i}
\mid K^2,
\qquad
d_z\equiv-K\pmod R.
\]

此前大多数计算只记录某个 \(d_z\) 是否存在，而没有记录同一目标有多少个指数表示。

## 2.2 近邻表示偶终端引理

### 定理

假设存在不同的

\[
z,w\in\mathcal Z^-_{R,K}
\]

满足

\[
|z_i-w_i|\le\nu_i
\qquad
\text{对每个 }i.
\]

则该 \((R,K)\) 状态自动具有一个合法偶终端。

### 证明

令

\[
\rho=\prod_iq_i^{z_i-w_i}.
\]

因为 \(z\ne w\)，由唯一分解可知 \(\rho\ne1\)。交换 \(z,w\) 后可假设

\[
0<\rho<1.
\]

逐坐标条件给出

\[
0\le\nu_i+z_i-w_i\le2\nu_i.
\]

因此

\[
U=K\rho
\]

是正整数，并满足

\[
U\mid K^2.
\]

令

\[
E=4U=4K\rho.
\]

由于 \(z,w\) 都表示 \(-1\)，有

\[
\rho\equiv1\pmod R.
\]

又因为

\[
4K=pR+1,
\]

所以

\[
E\equiv4K\equiv1\pmod R.
\]

同时

\[
E\mid4K^2,
\qquad
4\mid E,
\qquad
0<E<4K.
\]

于是

\[
n=\frac{4K-E}{R}
\]

是正偶数。并且 \(E\ge4\)，故

\[
4K-E\le4K-4<pR,
\]

所以

\[
2\le n<p.
\]

这就是合法偶终端。

## 2.3 一个粗但严格的装箱推论

对每个坐标区间

\[
[-\nu_i,\nu_i]
\]

分成两个直径不超过 \(\nu_i\) 的整数区间，例如

\[
[-\nu_i,0],
\qquad
[1,\nu_i].
\]

整个指数盒被分成

\[
2^r=2^{\omega(K)}
\]

个小盒。若

\[
\boxed{
|\mathcal Z^-_{R,K}|>2^{\omega(K)},
}
\]

鸽巢原理保证两个目标表示落在同一小盒，从而逐坐标距离不超过 \(\nu_i\)，自动得到偶终端。

因此：

\[
\boxed{
\text{目标表示纤维足够丰富}
\Rightarrow
\text{无需独立搜索终端}.
}
\]

## 2.4 为什么这是新突破口

这一机制利用的是

\[
\frac{-1}{-1}=1,
\]

但关键不在群论恒等式，而在两个表示之比仍留在允许的有限指数预算内。

它把目标侧和终端侧直接连接起来：

\[
\boxed{
\text{一个目标表示给 Type I，两个近邻目标表示给偶终端。}
}
\]

这比当前“先找目标、再独立找 \(E\)”更紧。

## 2.5 编码论解释

若一个命中状态不能通过该引理产生终端，则

\[
\mathcal Z^-_{R,K}
\]

必须是指数盒中的一种代码：任意两个不同码字都在至少一个坐标上相差超过 \(\nu_i\)。

粗装箱界给出

\[
|\mathcal Z^-|\le2^r.
\]

可以进一步引入加权 Lee 距离或 \(\ell_\infty\) 反码理论，寻找比 \(2^r\) 更强的上界。尤其当很多 \(\nu_i=1\) 或指数预算高度不均匀时，最优反码界可能显著更好。

## 2.6 建议主张

```text
type-I-target-fiber-near-pair-terminal
type-I-target-fiber-packing-terminal
```

两条均可标为 `established`，但应先做独立整数 verifier。

# 3. 突破点三：有限傅里叶分析统一 G 与 F 障碍

## 3.1 精确表示数公式

对 \(t\in H\)，定义表示数

\[
N_H(t)
=
\#\left\{
z\in B_\nu:
\phi(z)=t
\right\}.
\]

令

\[
M=|B_\nu|
=
\prod_{i=1}^r(2\nu_i+1).
\]

对字符群 \(\widehat H\)，有精确傅里叶展开：

\[
\boxed{
N_H(t)
=
\frac1{|H|}
\sum_{\chi\in\widehat H}
\overline{\chi(t)}
\prod_{i=1}^r
D_{\nu_i}\bigl(\chi(q_i)\bigr),
}
\]

其中

\[
D_\nu(\zeta)
=
\sum_{j=-\nu}^{\nu}\zeta^j
\]

是有限 Dirichlet 核。

平凡字符贡献主项

\[
\frac M{|H|}.
\]

其余字符描述指数盒随机游走偏离均匀分布的程度。

## 3.2 目标缺失迫使谱集中

若

\[
N_H(t)=0,
\]

则

\[
M
\le
\sum_{\chi\ne1}
\prod_i
\left|
D_{\nu_i}\bigl(\chi(q_i)\bigr)
\right|.
\]

因此至少有一个非平凡字符满足

\[
\boxed{
\prod_i
\frac{
\left|
D_{\nu_i}\bigl(\chi(q_i)\bigr)
\right|
}{
2\nu_i+1
}
\ge
\frac1{|H|-1}.
}
\]

Dirichlet 核的标准衰减表明：若写

\[
\chi(q_i)=e^{2\pi i\theta_i},
\]

则大的归一化乘积只可能在大量有权坐标上满足

\[
\theta_i\approx0\pmod1.
\]

更定量地，经过适当常数化，可以期待从上式推出：

\[
\sum_i
\min\left(
1,\,
\nu_i^2\|\theta_i\|_{\mathbb R/\mathbb Z}^2
\right)
\ll
\log|H|.
\]

这给出一个**近似分离角色**：

- G 型有精确字符使所有生成元落在核中，而目标不在核中；
- F 型没有精确支撑分离，但目标缺失仍迫使某个字符在大部分指数预算上近乎平凡。

## 3.3 一个严格可计算的终端充分条件

由傅里叶公式，

\[
N_H(-1)
\ge
\frac1{|H|}
\left(
M-
\sum_{\chi\ne1}
\prod_i
|D_{\nu_i}(\chi(q_i))|
\right).
\]

如果

\[
\boxed{
M-
\sum_{\chi\ne1}
\prod_i
|D_{\nu_i}(\chi(q_i))|
>
|H|\,2^{\omega(K)},
}
\]

则

\[
N_H(-1)>2^{\omega(K)},
\]

由目标纤维装箱引理自动得到偶终端。

这是一个完全严格的“傅里叶混合 \(\Rightarrow\) 混合终端”判据。

## 3.4 研究计划

对每个 F 状态计算：

1. 最大非平凡归一化傅里叶乘积；
2. 对应字符阶；
3. 相位预算
   \[
   \sum_i\nu_i^2\|\theta_i\|^2;
   \]
4. 该字符的活跃素因子集合；
5. 同一素数不同状态的最强字符是否共享导子或活跃素因子。

要检验的核心猜想不是“坏字符成对矛盾”，而是：

> 若同一素数的所有状态都失败，则每个状态都需要一个高集中度近角色；这些近角色所需的活跃素因子幂无法同时满足标签差和模数差的碰撞容量。

这把此前失败的“精确坏角色冲突”升级为**谱能量总量矛盾**。

# 4. 突破点四：几何数论的平坦性证书

## 4.1 关系格模型

令

\[
\Lambda=\ker\phi\subseteq\mathbb Z^r.
\]

因为 \(H\) 有限，\(\Lambda\) 是满秩有限指数格。

若 \(t=-1\in H\)，取一个整数原像 \(z_0\)，则全部表示为仿射格：

\[
\phi^{-1}(t)=z_0+\Lambda.
\]

F 型等价于

\[
(z_0+\Lambda)\cap B_\nu=\varnothing.
\]

也就是说，平移盒

\[
B_\nu-z_0
\]

相对于格 \(\Lambda\) 是无格点凸体。

## 4.2 平坦性给出的二分证书

近最优平坦性定理表明，在维数 \(r\) 中，无格点凸体必存在一个非零对偶方向

\[
y\in\Lambda^*
\]

使其格宽度至多

\[
O(r\log^3(2r)).
\]

对轴对齐盒，宽度为

\[
2\sum_i\nu_i|y_i|.
\]

因此 F 型应具有：

\[
\boxed{
\exists\,0\ne y\in\Lambda^*:
\quad
2\sum_i\nu_i|y_i|
\ll
r\log^3(2r).
}
\]

这条表达需要在仓库中仔细处理闭体/内点、零预算坐标和常数，但其结构非常清晰。

将 \(y\) 模 \(\mathbb Z^r\) 约化后有两种情况：

1. \(y\notin\mathbb Z^r\)：  
   它定义 \(H\) 的非平凡字符，且加权相位很短；
2. \(y\in\mathbb Z^r\)：  
   它不给出非平凡字符，但说明某个整数坐标组合的总指数宽度很小，即存在真实的小预算方向。

所以：

\[
\boxed{
\text{每个 F 型状态都应产生}
\quad
\text{短对偶角色}
\ \lor\
\text{小预算坐标组合}.
}
\]

这与仓库近期的单活跃素因子、二进矩形、低阶商模型高度一致：那些模型正是低维平坦方向的显式特例。

## 4.3 为什么它可能比逐个商群分类更强

当前方法按群阶、素数阶商、单活跃方向逐层分类。平坦性定理试图直接说明：

> 只要目标仿射格没进入指数盒，就一定存在低复杂度对偶见证。

它可能把大量不同商群结构统一成一个短向量问题。

## 4.4 计算实现

利用 Smith 正规形构造 \(\Lambda\)，再对加权对偶格求短向量：

\[
\min_{0\ne y\in\Lambda^*}
\sum_i\nu_i|y_i|.
\]

可先用：

- LLL 找候选；
- 小维枚举验证最优；
- MILP 或 branch-and-bound 求加权 \(\ell_1\) 最短向量。

每个 F 状态输出：

```text
weighted dual width
dual vector denominator/order
induced character
active coordinate support
comparison with current separator
```

若所有困难状态都给出极短低支撑向量，就有望形成可分类的逆结构定理。

# 5. 突破点五：把指数盒改写为带重数的子序列和

## 5.1 精确改写

把 \(H\) 写成加法群，令

\[
g_i=q_i\bmod R.
\]

则

\[
[-\nu_i,\nu_i]g_i
=
-\nu_i g_i
+
\{0,g_i,\ldots,2\nu_i g_i\}.
\]

后一个集合正是 \(2\nu_i\) 个 \(g_i\) 的子序列和。

令序列

\[
S=
\underbrace{g_1,\ldots,g_1}_{2\nu_1},
\ldots,
\underbrace{g_r,\ldots,g_r}_{2\nu_r}.
\]

则

\[
\boxed{
\mathcal C_R(K)
=
-\sum_i\nu_i g_i+\Sigma(S),
}
\]

其中 \(\Sigma(S)\) 是全部子序列和集合。

这一步保留了素因子指数的**重数**；把每个区间只当作一个普通集合会丢失这部分信息。

## 5.2 可调用的加法组合学工具

### DeVos–Goddyn–Mohar 型定理

这类定理对固定长度子序列和给出带稳定子的 Kneser 下界。可以：

- 对每个子序列长度层应用；
- 或加入零元素，把不定长度问题转成固定长度；
- 追踪重复生成元对稳定子商的贡献。

### Kemperman 临界对结构

若一个无周期和集几乎达到 Kneser 下界，则因子通常必须落入：

- 同方向算术级数；
- 准周期分解；
- 少数有限例外结构。

这比当前只使用数值下界更有价值。当前的“单活跃素因子循环商”和“二进—奇素矩形”很可能就是一般临界结构的秩一投影。

### Pollard 型流行和集

Pollard 理论不仅控制和集大小，还控制元素的表示重数。它与目标纤维近邻机制天然匹配：

\[
\text{表示数丰富}
\Rightarrow
\text{目标近邻对}
\Rightarrow
\text{偶终端}.
\]

## 5.3 建议的中间定理

目标不是立即引用一个现成定理关闭猜想，而是证明一个适配当前序列的二分：

\[
\boxed{
\begin{array}{l}
\Sigma(S)\text{ 对目标有足够多表示}
\Rightarrow\text{偶终端};\\[1mm]
\Sigma(S)\text{ 的目标表示稀疏}
\Rightarrow
S\text{ 在某个商中集中于低秩进程或准周期结构}.
\end{array}}
\]

然后把低秩结构拉回到：

- 少量活跃素因子；
- 标签差；
- 模数差；
- 二进方向；
- 固定层稳定子。

## 5.4 最小可攻问题

先不要做完整多层逆定理。建议从以下问题开始：

> 对两个中心化区间 \(A,B\subseteq C_n\)，若 \(A+B\) 无周期、未命中阶二目标，且
> \[
> |A+B|\le |A|+|B|+c
> \]
> 对小常数 \(c\)，分类 \(A,B\) 的可能形状。

随后再加入第三层。这样可以直接覆盖仓库当前最常见的两块和四层状态。

# 6. 突破点六：推广比值二为 \(2^j\) 传输

近期仓库只系统使用了

\[
a\equiv2b\pmod R.
\]

但偶终端同余真正需要的是把一个除子比值乘到

\[
2L=4K\equiv1\pmod R.
\]

这可以推广到任意二次幂。

## 6.1 广义二进传输引理

令

\[
L=2K,
\qquad
\ell=v_2(L).
\]

设 \(a,b\mid L\) 互素，且对某个 \(j\ge1\) 有

\[
a\equiv2^j b\pmod R.
\]

定义

\[
\boxed{
E_j
=
2^{1-j}L\frac ab.
}
\]

若二进指数满足

\[
\boxed{
1
\le
\ell+v_2(a)-v_2(b)+1-j
\le
2\ell,
}
\]

则 \(E_j\) 是偶数且

\[
E_j\mid L^2=4K^2.
\]

又因为

\[
a/b\equiv2^j\pmod R,
\]

所以

\[
E_j
\equiv
2^{1-j}L\cdot2^j
=
2L
=
4K
\equiv1\pmod R.
\]

若进一步有

\[
a<2^j b
\quad\text{且}\quad
E_j>1,
\]

则

\[
0<E_j<2L=4K,
\]

从而

\[
n=\frac{2L-E_j}{R}
\]

是满足

\[
2\le n<p
\]

的正偶数。

因此得到合法偶终端。

## 6.2 与现有结果的关系

\(j=1\) 正好恢复比值二终端。

新自由度 \(j>1\) 允许：

- 使用更高二进预算；
- 适配当前商群中的二进方向 \(\alpha\)；
- 在 \(D_R(L)\cap2D_R(L)\) 为空时，寻找
  \[
  D_R(L)\cap2^jD_R(L).
  \]

## 6.3 立即可做的计算

对每个当前比值二失败状态，计算最小合法 \(j\)：

```text
min_j with a ≡ 2^j b (mod R)
2-adic exponent legality
orientation a < 2^j b
terminal height n
```

这会回答一个非常实际的问题：

> 比值二失败究竟是终端机制失败，还是只因为固定使用了 \(j=1\)？

## 6.4 建议主张

```text
type-I-normal-generalized-dyadic-ratio-terminal
```

该引理可直接证明，应与现有二进平衡主张连接。

# 7. 突破点七：跨状态 \(p\)-进碰撞容量

## 7.1 从成对兼容升级为全局容量

仓库已经证明，在若干单活跃模型中，同一活跃素因子幂若跨状态重复出现，会强制：

\[
q^h\mid\text{标签差}
\]

或

\[
q^h\mid\text{模数差}.
\]

此前主要把这用于成对兼容审计。更强的用法是把它变成一个全局装箱界。

## 7.2 一个基本容量引理

设不同整数标签 \(t_i\) 全部位于长度 \(M\) 的区间中，并给每个标签一个需求高度 \(h_i\ge1\)。

如果对每个 \(h\)，所有满足 \(h_i\ge h\) 的标签都同余于同一个模 \(q^h\) 剩余类，那么

\[
\#\{i:h_i\ge h\}
\le
\left\lfloor\frac{M}{q^h}\right\rfloor+1.
\]

于是

\[
\boxed{
\sum_i h_i
=
\sum_{h\ge1}\#\{i:h_i\ge h\}
\le
\sum_{h\ge1}
\left(
\left\lfloor\frac{M}{q^h}\right\rfloor+1
\right),
}
\]

求和只需到最大需求高度。

这给出了一个重复活跃素因子的总 \(q\)-进容量。

若标签相同，则改用同标签纤维中的模数差刚性，得到另一份容量界。

## 7.3 如何与素数阶商预算结合

在素数阶无周期商 \(\ell\) 中，持续 F 型需要

\[
2\sum b_i\le\ell-2.
\]

另一方面，傅里叶或平坦性可能说明每个失败状态至少需要某些活跃指数总量：

\[
\sum b_i\ge B_{\min}(R,K).
\]

若同一个素因子 \(q\) 在很多状态中承担这些预算，则跨状态碰撞容量限制其重复次数。

可能的全局矛盾形式是：

\[
\boxed{
\sum_{\text{失败状态}}
\text{所需活跃预算}
>
\sum_q
\text{标签/模数允许的 }q\text{-进容量}.
}
\]

这是一条真正把局部有限群障碍连接到全称状态选择的路线。

## 7.4 风险

当前跨状态整除定理只覆盖特定活跃模型。要推广到一般多方向状态，需要：

- 为每个状态选择一个规范主活跃方向；
- 控制同一状态可能有多种分离角色；
- 处理标签重复；
- 防止预算在多个素因子间自由迁移。

因此这是高风险路线，但它直接瞄准当前唯一缺失的“跨状态存在性”。

# 8. 突破点八：随机游走、逆 Littlewood–Offord 与结构—混合二分

## 8.1 概率模型

令各坐标独立均匀：

\[
Z_i\sim\operatorname{Unif}\{-\nu_i,\ldots,\nu_i\}.
\]

则

\[
X=\prod_iq_i^{Z_i}\in H
\]

是一条有限群随机游走的终点。

目标概率为

\[
\Pr[X=t]
=
\frac{N_H(t)}M.
\]

若随机游走充分混合，则

\[
N_H(t)\approx\frac M{|H|}.
\]

当

\[
\frac M{|H|}
\gg
2^{\omega(K)}
\]

且误差可控时，目标纤维装箱引理会给出终端。

## 8.2 逆 Littlewood–Offord 哲学

若某个点质量异常大，或分布远离均匀，逆 Littlewood–Offord 理论通常说明生成元集中在低秩广义算术级数中。

在当前有限扭群、有界非伯努利系数场景中，不能直接照搬经典整数定理；但可以建立适配版本：

\[
\boxed{
\text{随机游走不混合}
\Rightarrow
\text{大部分有权生成元在低秩商或近角色核中}.
}
\]

这与傅里叶和格平坦性给出的证书是同一个现象的三种语言：

- 傅里叶：存在大谱系数；
- 格论：存在短对偶方向；
- 逆 Littlewood–Offord：生成元有低秩结构。

## 8.3 一个建议的三分定理

尝试证明：

\[
\boxed{
\begin{array}{ll}
\text{I. 混合：}
&
N_H(-1)>2^{\omega(K)}
\Rightarrow\text{偶终端};\\[1mm]
\text{II. 稀疏命中：}
&
1\le N_H(-1)\le2^{\omega(K)}
\Rightarrow\text{目标纤维是低容量代码};\\[1mm]
\text{III. 缺失：}
&
N_H(-1)=0
\Rightarrow\text{存在高集中度非平凡字符}.
\end{array}}
\]

第二类是最关键的中间区。它可以通过编码论、Kemperman 逆结构或短关系格来处理。

- 数学状态：可立即严格证明；

- 风险：低；

### B1. 傅里叶缺失 \(\Rightarrow\) 近角色

- 理论基础：标准字符展开与 Dirichlet 核；
- 价值：统一 G/F；
- 风险：中；
- 关键：把谱集中拉回跨状态算术约束。

- 理论基础：成熟；
- 价值：把数值缺陷变成结构分类；
- 风险：中；
- 关键：适配多重指数区间和指定阶二目标。

- 理论基础：近最优平坦性定理；
- 价值：统一所有 F 型为短对偶证书；
- 风险：中；

## C 级：高风险、高突破潜力

### C1. 跨状态 \(p\)-进容量矛盾

- 价值：直接处理全称选择；
- 风险：高；
- 难点：规范选择活跃方向和处理预算迁移。

### C2. 有限扭群逆 Littlewood–Offord

- 价值：可能给出统一结构—混合二分；
- 风险：高；
- 难点：经典定理多针对整数或无挠群，需要适配有限群和非均匀指数区间。

目标纤维近邻引理负责第一件事；傅里叶、平坦性、Kemperman 与 \(p\)-进碰撞负责第二件事。
