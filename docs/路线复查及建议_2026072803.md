# 一、线性块的“标签碰撞刚性”可以立即写成定理

对同一个 (p) 的任意线性状态

[
p=a+s+asR,
]

把两个端点标签统一记为 (t\in{a,s})，定义相应块

[
D_{(t,R)}=tR+1.
]

则有

[
D_{(t,R)}\mid p-t,
]

并且一个状态的两个块满足

[
(aR+1)(sR+1)=pR+1=4K.
]

现在取两个可能来自不同状态的块

[
D_{(t,R)}=tR+1,\qquad
D_{(u,R')}=uR'+1.
]

## 不同标签

若 (t\ne u)，则

[
\boxed{
\gcd(D_{(t,R)},D_{(u,R')})\mid |t-u|.
}
]

证明只有一行：

[
\gcd(D_{(t,R)},D_{(u,R')})
\mid\gcd(p-t,p-u)
\mid |t-u|.
]

因此若

[
q^\nu\mid D_{(t,R)},D_{(u,R')},
]

则必有

[
q^\nu\mid t-u.
]

这比“公共素因子来自标签差”更精确：标签差还同时控制可共享的最高素数幂指数。

## 相同标签

若标签相同而 (R\ne R')，则有精确恒等式

[
\boxed{
\gcd(tR+1,tR'+1)
================

\gcd(tR+1,R-R').
}
]

因为

[
(tR'+1)-(tR+1)=t(R'-R)
]

且

[
\gcd(tR+1,t)=1.
]

所以同标签纤维中的共享因子也不是完全自由的，它由模数差控制。

## 完整碰撞层

对完整有限线性谱中的一个块 (D_{(t,R)})，定义

[
J_{t,R}
=======

\operatorname{lcm}\left(
{|t-u|:u\ne t}
\cup
{|R-R'|:(t,R')\ne(t,R)}
\right).
]

则

[
S_{t,R}=\gcd(D_{(t,R)},J_{t,R})
]

包含该块中所有可能与其他块共享的指数层，而

[
P_{t,R}=\frac{D_{(t,R)}}{S_{t,R}}
]

是无法在任何其他块中以相同额外指数出现的层。

这里最好称 (P_{t,R}) 为：

> **谱内不可共享的过剩指数层**

而不是笼统称为“私有素因子”，因为同一个素数可能在其他块中以较低指数出现。

这应当单独建立为：

```text
type-I-linear-labeled-block-gcd-rigidity
```

它与你已有的跨模数

[
\gcd(K_R,K_{R'})
================

\gcd\left(K_R,\frac{|R-R'|}{4}\right)
]

是互补的：现有定理控制整个 (K_R)，新定理控制组成 (K_R) 的两个带标签因子块。([GitHub][4])

# 二、碰撞—私有分解本身仍不能强制目标命中

这一点必须提前写入理论边界，否则很容易重复固定 AC 扇的失败。

即使一个大素因子 (q) 只属于一个标签或一个状态，也完全可能满足

[
\chi_R(q)=1
]

而落在该状态局部分离角色的核中。它的“私有性”只表示没有第二个块共享这个整数因子，并不表示它的模 (R) 剩余类一定能够破坏角色障碍。

现有完整谱已经显示：

* 四点全谱中的 12 个一般 (B) 命中，没有一个由谱内私有块单独完成；
* 其中 8 个必须混合私有块和共享块；
* 按源块 (\gamma) 与仿射块 (L) 分割时，20 个定向命中中有 16 个必须混合两块。([GitHub][5])

因此正确的用途不是

[
\text{“出现一个私有因子”}\Longrightarrow\text{命中},
]

而应当是

[
\text{碰撞层提供初始积集}
+
\text{私有层推动积集或破坏角色核}.
]

这也解释了为什么总乘积角色信息没有作用：两个原始块都同余于 (1\pmod R)，只看它们的角色总积必然得到 (1)，会丢失逐素因子的角色分布。([GitHub][6])

# 三、从线性块中可以推出一个新的 (2)-残数逃逸引理

这是当前骨架里最容易立即获得的非平凡强化。

假设线性状态的某个端点标签满足

[
t\equiv3\pmod4.
]

因为

[
p\equiv1\pmod4,\qquad R\equiv3\pmod4,
]

另一个端点标签 (u) 必为奇数。于是两个块均为偶数，且

[
\gamma=\frac{tR+1}{2},\qquad
L=\frac{uR+1}{2}
]

都是整数，并满足

[
K=\gamma L.
]

模 (R) 有

[
2\gamma=tR+1\equiv1\pmod R,
]

所以

[
\gamma\equiv2^{-1}\pmod R.
]

由于 (\gamma\mid K)，得到

[
\boxed{
2\in\mathcal H_R(K).
}
]

实际上中心化平方除子谱中已经有

[
\boxed{
2,\ 2^{-1}\in\mathcal C_R(K).
}
]

因此，任意子群障碍的分离角色

[
\chi(q)=1\quad(q\mid K),\qquad
\chi(-1)\ne1
]

必须同时满足

[
\boxed{\chi(2)=1.}
]

这比仓库中一般状态只能推出的 (\chi(4)=1) 严格更强。

## 两个直接推论

若分离角色是平方自由导子 (m) 的二次角色

[
\chi(n)=\left(\frac nm\right),
]

则

[
\chi(-1)=-1
\quad\Longrightarrow\quad
m\equiv3\pmod4,
]

而

[
\chi(2)=1
\quad\Longrightarrow\quad
m\equiv\pm1\pmod8.
]

所以必有

[
\boxed{m\equiv7\pmod8.}
]

更一般地，若

[
-1\in\langle2\bmod R\rangle,
]

那么 (2\in\mathcal H_R(K)) 已经强制

[
-1\in\mathcal H_R(K),
]

故子群障碍不可能发生。

特别地：

[
\boxed{
R\text{ 为素数},\quad
R\equiv3\pmod8,\quad
\text{某个端点 }t\equiv3\pmod4
\Longrightarrow
\text{该状态不是 G 型障碍}.
}
]

因为 Euler 判据给出

[
2^{(R-1)/2}\equiv-1\pmod R.
]

它仍可能是有限指数 F 型，但至少已经严格消灭了角色障碍。

建议新增两张卡：

```text
type-I-linear-two-adic-support-injection
type-I-linear-prime-modulus-subgroup-escape
```

# 四、二次障碍存在一个显式的跨模数互反拉回

这可能是你目前最有价值的新理论桥。

设一个线性状态的二次障碍角色由平方自由导子

[
m\mid R
]

给出：

[
\chi_m(x)=\left(\frac xm\right),\qquad
\chi_m(-1)=-1.
]

于是 (m\equiv3\pmod4)。令

[
c=\frac Rm.
]

任取奇素数 (q\mid K)。因为

[
4K=(aR+1)(sR+1),
]

所以 (q) 至少整除某个标签块

[
tR+1.
]

同时

[
tR+1\mid p-t,
]

故

[
p\equiv t\pmod q.
]

又由 (R=mc) 及 (tR\equiv-1\pmod q)，得到

[
m\equiv-(tc)^{-1}\pmod q.
]

二次互反律于是给出

[
\begin{aligned}
\left(\frac qm\right)
&=
\left(\frac{-1}{q}\right)
\left(\frac mq\right)\
&=
\left(\frac{-1}{q}\right)
\left(\frac{-(tc)^{-1}}q\right)\
&=
\left(\frac{tc}{q}\right)\
&=
\left(\frac{pc}{q}\right).
\end{aligned}
]

所以有精确恒等式

[
\boxed{
\chi_m(q)
=========

# \left(\frac qm\right)

\left(\frac{p(R/m)}q\right)
\qquad(q\mid K,\ q\text{ 为奇素数}).
}
]

这把模 (R) 上变化的二次角色，拉回成了 (K) 的实际素因子 (q) 上的普通 Legendre 符号。

## 特别重要的素模数情形

若 (R) 本身是素数，则 (m=R)、(c=1)，因此

[
\boxed{
\left(\frac qR\right)=\left(\frac pq\right)
\qquad(q\mid K,\ q\text{ 奇}).
}
]

而 (R\equiv3\pmod4) 为素数时，G 型障碍恰好意味着 (K) 的全部素因子都是模 (R) 的二次剩余。因此：

> 素模数状态的 G 型障碍，可以等价描述为：
> (K) 的所有奇素因子都在二次域 (\mathbb Q(\sqrt p)) 中分裂，并满足相应的 (2)-局部条件。

这第一次给出了真正可跨不同 (R) 比较的对象：不是比较不同单位群中的抽象角色，而是比较实际素因子在一族二次域中的分裂行为。

对于一般复合导子，所对应的二次域是

[
\mathbb Q\left(\sqrt{pR/m}\right).
]

因此“碰撞层—私有层”可以被重新解释为：

* 碰撞素因子必须同时满足多个分裂条件；
* 私有素因子只承担当前状态的一组分裂条件；
* 要逃离 G 型障碍，只需在某个状态找到一个不分裂的素因子。

这仍不能直接证明逐点存在，因为有限多组素因子完全可能同时分裂；十条 AC 射线反例正好说明了这种有限相容性确实会发生。但它为筛法、Chebotarev 型启发式以及同标签纤维比较提供了明确的算术坐标。

还必须保留高阶角色边界：四点完整谱中的 126 个子群障碍有 124 个可由二次角色分离，但另有 2 个首次需要四阶角色。因此纯二次互反路线不能独立完成全称证明，最终要么加入四次互反/二幂角色拉回，要么证明高阶状态必被其他源状态替代。([GitHub][7])

建议建立：

```text
type-I-linear-quadratic-obstruction-reciprocity-pullback
```

# 五、有限指数障碍可以改写成“反足点不相交”

对固定 ((R,K))，定义普通的单边除子剩余谱

[
\mathcal A_R(K)
===============

{d\bmod R:d\mid K}.
]

已有中心化平方除子谱为

[
\mathcal C_R(K)
===============

\left{
\prod_{q\mid K}q^{z_q}:
-\nu_q(K)\le z_q\le\nu_q(K)
\right}.
]

每个 (z_q) 都可写成

[
z_q=e_q-f_q,\qquad
0\le e_q,f_q\le\nu_q(K),
]

所以有精确恒等式

[
\boxed{
\mathcal C_R(K)
===============

\mathcal A_R(K)\mathcal A_R(K)^{-1}.
}
]

因此

[
\begin{aligned}
-1\in\mathcal C_R(K)
&\iff
\exists,u,v\mid K:\ uv^{-1}\equiv-1\pmod R\
&\iff
\exists,u,v\mid K:\ u\equiv-v\pmod R\
&\iff
\boxed{
\mathcal A_R(K)\cap
\bigl(-\mathcal A_R(K)\bigr)\ne\varnothing.
}
\end{aligned}
]

而对应的目标平方除子可直接恢复为

[
d=\frac{Ku}{v}\mid K^2,
\qquad
d\equiv-K\pmod R.
]

这把一般 (B) 目标变成了一个非常直观的有限群问题：

> (K) 的普通除子剩余类集合，是否与自己的负集相交？

## F 型障碍的半密度约束

若已经不是 G 型，即

[
-1\in\mathcal H_R(K),
]

但仍是有限指数 F 型，那么

[
\mathcal A_R(K)
\cap
-\mathcal A_R(K)
================

\varnothing.
]

两集合都位于同一个子群 (\mathcal H_R(K)) 内且大小相同，所以必有

[
\boxed{
2|\mathcal A_R(K)|
\le
|\mathcal H_R(K)|.
}
]

于是得到一个简单而严格的充分条件：

[
\boxed{
-1\in\mathcal H_R(K)
\quad\text{且}\quad
|\mathcal A_R(K)|>
\frac{|\mathcal H_R(K)|}{2}
\Longrightarrow
\text{目标命中}.
}
]

临界等号情形也很刚性：若仍不命中，则

[
\mathcal A_R(K)\sqcup-\mathcal A_R(K)
=====================================

\mathcal H_R(K),
]

即除子谱必须恰好从每一对 ({h,-h}) 中选择一个。

## 与两块分解的结合

若

[
K=\gamma L,
]

即使 ((\gamma,L)\ne1)，仍有精确积集恒等式

[
\boxed{
\mathcal A_R(K)
===============

\mathcal A_R(\gamma)\mathcal A_R(L).
}
]

因为 (K) 的每个素数指数区间

[
[0,\nu_q(\gamma)+\nu_q(L)]
]

都是两个区间之和。

所以现有的“两块混合命中”现在可以解释为：

[
\mathcal A_R(\gamma)
\quad\text{和}\quad
\mathcal A_R(L)
]

单独都未接触自己的负集，但乘积集开始出现反足点碰撞。这与仓库中 16/20 个定向命中必须混合源块和仿射块完全吻合。([GitHub][8])

建议新增：

```text
type-I-general-b-antipodal-divisor-spectrum
```

这是处理 F 型障碍比“等待整个中心化盒完全饱和”更弱、更自然的目标。

# 六、下一阶段应拆成两个独立的数学里程碑

现在不要直接试图证明一句过强的：

[
\text{“所有线性状态不可能同时坏。”}
]

更适合拆为两个阶段。

## 第一阶段：支撑逃逸

证明某个线性状态满足

[
-1\in\mathcal H_R(K).
]

可用的机制包括：

[
2\in\mathcal H_R(K)
]

与

[
-1\in\langle2\bmod R\rangle,
]

或者通过二次互反拉回找到一个素因子 (q\mid K)，使

[
\left(\frac{pR/m}{q}\right)=-1,
]

从而破坏相应的二次分离角色。

这一阶段只负责把状态从 G 推入

[
{\text{F},\text{命中}}.
]

## 第二阶段：反足点逃逸

在已经有

[
-1\in\mathcal H_R(K)
]

的状态上，证明

[
\mathcal A_R(K)\cap-\mathcal A_R(K)\ne\varnothing.
]

碰撞—私有分解在这里可以通过两种方式使用：

1. 证明私有指数层使
   [
   |\mathcal A_R(K)|>\frac12|\mathcal H_R(K)|.
   ]
2. 按商群阶逐层加入私有素因子。若基础碰撞层已经在其子群中饱和，而新增 (q^{\nu}) 在当前商群中的阶不超过 (\nu+1) 或中心化版本的 (2\nu+1)，就能逐层填满相应商群。

仓库已有“一私有素因子的三余类饱和判据”，上述方法是它对多个碰撞/私有指数层的自然推广。([GitHub][9])

七点完整谱中，两类失败在每一个素数内都实际出现：总计 20 个命中、190 个 G 型和 68 个 F 型。因此只完成角色逃逸或只完成指数盒饱和都不足以推出选择器。([GitHub][10])

# 八、反例搜索也应针对完整线性选择器

十条 AC 射线的经验已经说明：固定有限菜单可以全部制造成 G 型，却可能被一个未纳入菜单的普通双尾或线性状态立即关闭。

因此新的对抗搜索应当以完整对象为单位：

1. 先筛出普通 Type II 双尾遗漏；
2. 优先选择 (\tau((p-1)/4)) 和完整线性 (R) 数较小的素数；
3. 对每个候选完整枚举全部线性状态；
4. 计算
   [
   N_{\rm hit}(p),\quad N_G(p),\quad N_F(p);
   ]
5. 优先保留
   [
   N_{\rm hit}(p)=1
   ]
   且唯一命中结构复杂、其余状态障碍较深的点；
6. 真正的反例候选必须满足
   [
   N_{\rm hit}(p)=0,
   ]
   而不是只让一个预先规定的状态扇同时失败。

(p=878089) 目前仍是理想原型：24 个不同 (R) 中只有 (R=59) 命中，其余为 21 个 G 和 2 个 F。它显示一个成功状态必须同时逃离两类大量局部障碍。([GitHub][11])

# 当前最值得押注的理论桥

综合这些结果，我会把下一阶段主命题压缩成：

[
\boxed{
\begin{array}{c}
\text{线性块的标签差刚性}\
+\ \text{二次角色的互反拉回}\
+\ \text{除子谱的反足点增长}
\end{array}
}
]

具体分工是：

[
\boxed{
\text{互反拉回和 }2\text{-残数机制处理 G；
碰撞—私有积集增长处理 F。}
}
]

其中最重要的新公式是

[
\boxed{
\left(\frac qm\right)
=====================

\left(\frac{pR/m}{q}\right),
}
]

它提供了此前缺失的显式跨源角色坐标；而

[
\boxed{
\mathcal A_R(K)\cap-\mathcal A_R(K)\ne\varnothing
}
]

则把有限指数问题改写成了可以使用 Kneser 型积集增长、商群阶和碰撞指数层的目标。

这两个结果都还没有关闭全称选择引理，但它们把“所有状态为什么不能同时坏”分解成了两个可以分别证明、分别制造反例、并可用完整谱精确审计的数学问题。
