# 路线复查及建议 v2

更新日期：2026-07-27

## 结论

当前路线已经产生三项实质结论：

1. 增长规范 Type II 移位扇的变维筛可以通过大素数截断
   \(Y=\exp(H^2)\) 严格闭合，并可强化到每个固定
   \(\alpha>0\) 的
   \(H=\lfloor(\log\log X)^\alpha\rfloor\)；
2. “动态低缺陷 tail 或动态外源出口”在真实有限例外集
   \(E_{\mathrm{new}}(10^7,100)\) 上实现了 \(7056/7056\) 的精确联合覆盖，
   并已用固定低缺陷 Type II 见证覆盖两条最困难 H19-k23 原压力进程的全部参数。
3. 同一二分选择器的全称 `Selector-Enew` 已被
   \(E_{\mathrm{new}}(10^6,20)\) 中的 \(214729,297049,878089\) 三个完整穷尽反例否定。

这三项结论都没有证明 Erdős--Straus 猜想。第一项是密度定理，允许稀薄但可能无穷的
例外；第二项是较大窗口中的有限机制资料和压力进程定理；第三项只否定当前 T/E 二分法，
不说明三个素数没有其他证书。

因此下一阶段不应再尝试证明已被否定的二分选择器，而应研究：

> 将三个反例已有的 `AC_2` 终端短证书纳入第三分支，并证明或否定“纯新证书、T/E 严格
> 递降或状态依赖 AC 终端证书”的新逐点接口。

## 一、证据口径

项目中的“状态”“来源”和“审查”是三个独立维度，不能合并成一个“已证”标签。

| 结论类型 | 应使用的主要状态 | 可以断言什么 | 不能断言什么 |
| --- | --- | --- | --- |
| 外部文献定理 | `established`，并记录外部原始来源 | 原文中确有该定理，且适用条件已经核对 | 仓库的新推论自动获得同行评议 |
| 仓库推导 | `established` + `repository_derivation` | 仓库保存了完整证明 | 已经外部审稿或发表 |
| 独立重推 | `review_status: independent_review` | 有一份不依赖原证明逐行照抄的复核 | 等同于外部同行评议 |
| 有限计算 | `computationally_reproduced` + `computational_reproduction` | 指定输入、范围和枚举规则内的结果可复现 | 对无限范围成立 |
| 已反驳选择器 | `contradicted` + `computational_reproduction` | 有经过完整枚举和独立重放的明确反例 | 反例自动否定原猜想 |

所有文献卡、主张卡和概念卡数量以 `python3 scripts/kb.py status` 的即时输出为准，不在
本文件手工维护。定理账本应由知识库生成，避免 README、综述和索引之间再次出现数字漂移。

## 二、必须区分的四个研究对象

当前最容易造成错误推断的问题，是把四个来源不同、量词不同的对象都称为“H19 例外”。

### 1. 真实筛例外 \(E_{\mathrm{new}}(X,H)\)

这是增长规范移位筛的真实补集。它由程序直接按定义生成：对
\(p\le X\)、\(p\equiv1\pmod{24}\) 的素数，要求每个
\(20\le s\le H\) 都没有满足规范残数条件且不属于前 19 个移位旧支持的素因子。
精确定义见[动态低缺陷 tail 或外源出口选择器](../claims/dynamic-low-defect-tail-or-external-exit-selector.md)。

只有这个集合可以直接与变维筛定理对接。后面的 211、664 和压力进程都不能替代
\(E_{\mathrm{new}}(X,H)\)。

### 2. 211 个同证书标记桥遗漏

这 211 个点来自 \(p\le10^9\) 的 541 个 H19 新因子状态，并且只表示：在
\(20\le s\le1008\) 的纯新规范证书窗口内，没有找到同一张证书诱导的缩放首项标记桥。
它们见[纯新规范证书的缩放首项标记尾边界](../claims/type-II-h19-pure-new-scaled-tail-mark-boundary-1b.md)。

这不是 \(E_{\mathrm{new}}\)：这些点已经有纯新证书，只是同证书标记提升失败。该有限集又被
另一张普通 Type II 双尾或外源递降完全闭合：

\[
211=210_{\text{另一张普通 Type II 双尾}}+1_{\text{自适应外源}}.
\]

因此它的作用是显示“必须允许换证书或换来源”，而不是充当筛例外样本。

### 3. 664 个 H19 十亿残余

这 664 个点是 \(p\le10^9\) 中前 19 条规范 Type II 射线未命中的有限残余。它们已经有
精确严格递降闭合：

\[
664=662_{\text{普通 Type II 双尾递降}}+2_{\text{自适应外源递降}}.
\]

证据见[H19 十亿残余的全严格递降闭合](../claims/type-II-h19-all-strict-descent-closure.md)。
这个结果证明有限剖面内“多来源递降”有效，但没有给出范围外的统一选择规则，也不能推出
某个固定缺口或固定尺度上界。

### 4. H19-k23 仿射压力进程

这是由固定尾菜单的失败状态构造出的仿射进程，不是自然区间中的有限残余集合。现有 22 条
进程中，20 条具有整条进程有效的固定因子外源桥；两条仍没有这类固定桥，见
[全局尾压力进程的固定因子外源桥](../claims/h19-k23-global-tail-pressure-external-source-bridge-2097152.md)。

这两条进程曾是当前最硬的开放压力作用域。两个种子已有变量因子外源出口；更强的新结果
分别用 \(q=15,d=37845\) 与 \(q=90,d=121014\) 的固定 Type II 见证覆盖原始步长
上的全部参数，而且两个见证的新增支持大小都为 1。因此 22 条压力进程现在形成
\(20\) 条固定外源桥加 \(2\) 条固定低缺陷尾的完整分流。

## 三、变维增长筛：数学审计已经闭合

### 3.1 旧证明的缺口

旧版证明直接从 \(4H\) 开始筛，并把“增长筛维的正则性”压缩为一句话。单侧筛积上界不足以
验证基本引理要求的区间比值；模数随 \(H\) 境长时，算术级数中的素数倒数和也需要明确的
一致适用区间。因此旧参数化不能作为独立可审稿证明保留。

### 3.2 大素数截断

令

\[
A_H=\sum_{20\le s\le H}\frac1{\varphi(M_s)},
\qquad \kappa_H=1+A_H,
\qquad Y=\exp(H^2).
\]

只筛素数 \(\ell>Y\)。因为 \(M_s\le4H\le\log Y\)，对所有相关模数可以统一使用
Siegel--Walfisz 型算术级数估计。于是对 \(v\ge Y\)，

\[
\sum_{Y<\ell\le v}\frac{\nu_H(\ell)}{\ell}
=\kappa_H\log\frac{\log v}{\log Y}+O(1),
\]

并且

\[
\sum_{\ell>Y}\frac{\nu_H(\ell)^2}{\ell^2}
\ll \frac{H^2}{Y},
\qquad
V_H(v)\asymp\left(\frac{\log Y}{\log v}\right)^{\kappa_H}.
\]

这给出基本筛引理需要的双侧正则性，而不再依赖未经证明的单侧估计。取
\(D=X^{1/3}\)，再令筛参数随 \(\kappa_H\) 增长，可得到

\[
E(X,H)
\ll
X\left(\frac{C\kappa_H H^2}{\log X}\right)^{\kappa_H}
+D(1+\log D)^H+O(z+H).
\]

利用

\[
A_H\ge\frac14\log H-O(1),
\]

可推出：对每个固定 \(\alpha>0\)，取

\[
H=\left\lfloor(\log\log X)^\alpha\right\rfloor,
\]

都有某个依赖于 \(\alpha\) 的 \(c_\alpha>0\)，使

\[
E(X,H)\ll_\alpha
X\exp\bigl(-c_\alpha(\log\log X)\log\log\log X\bigr).
\]

这里的 \(\alpha\) 必须预先固定；结论不对 \(\alpha\to0\) 一致。它强化了原先只取
\(H\asymp\log\log X\) 的版本。

数学状态是“仓库推导已完成独立重推”。主张卡已经用这份截断证明替换旧证明，补入
Siegel--Walfisz 与显式基本筛引理的原始定位，并通过知识库验证。对应入口是
[增长规范移位扇的超对数稀薄尾部](../claims/type-II-pure-new-canonical-fan-superlog-tail.md)。

### 3.3 这项结果改变了什么

这项定理推进了“几乎所有核心素数”的边界：规范移位窗口可以取任意固定次幂的
\(\log\log X\)，不再只限于一个足够小的线性倍数。它没有推进逐点边界；若例外集无穷，
再强的密度衰减也不能单独完成猜想。

## 四、动态选择器：反例、有限机制与后续缺口

令 \(B=(p-1)/4\)。现已被反驳的二分选择器允许两个随 \(p\) 变化的分支：

- 分支 T：选取任意 \(q\mid B\)，要求相应 Type II 双尾除子相对
  \(\operatorname{Supp}(q)\) 的新增素因子支持数至多 2；
- 分支 E：选取任意 \(k\mid B\)，要求严格较小外源的完整平方尾除子同余成立。

精确公式、提升恒等式和反例口径见
[动态低缺陷 tail 或外源出口选择器](../claims/dynamic-low-defect-tail-or-external-exit-selector.md)。

### 4.1 最小窗口的完整反例

对 \(X=1000000\)、\(H=20\)，程序从 9,732 个核心素数按定义生成了 9,195 个
\(E_{\mathrm{new}}(X,H)\) 元素。三点

\[
214729,\qquad297049,\qquad878089
\]

同时没有 T 与 E 见证。独立审计对每个点完整枚举 \(q\mid B\)、\(d\mid(B+q)^2\) 及
\(k\mid B\)、\(e\mid M_k^2\)：T 甚至没有任何满足同余的普通 Type II 除子，E 也没有
完整平方尾命中。详见
[真实 E_new(100 万,20) 中动态 T/E 选择器的三个完整反例](../claims/type-II-pure-new-exception-selector-counterexample-1m-h20.md)。

所以 `Selector-Enew` 已被否定；这不是 Erdős--Straus 猜想反例，也不能由提高支持缺陷阈值
修复，因为 T 的全部同余候选为空。三个点都有 \(\max(A,C)\le2\) 的直接 AC Type II
终端证书，故它们是旧递降接口的反例，而不是短证书障碍。

### 4.2 较大窗口的有限机制资料

对 \(X=10000000\)、\(H=100\)，程序从 82,887 个核心素数按定义生成了 7,056 个
\(E_{\mathrm{new}}(X,H)\) 元素。完整枚举结果为：

| 可用分支 | 数目 |
| --- | ---: |
| T 与 E 都可用 | 7016 |
| 仅 T 可用 | 32 |
| 仅 E 可用 | 8 |
| 两者都不可用 | 0 |

因此联合覆盖为 \(7056/7056\)。T 分支覆盖的 7,048 点中，最小支持缺陷分布为
\(6,790\) 个缺陷 0、\(258\) 个缺陷 1、没有点需要缺陷 2。仅由 E 分支覆盖的点有 8 个；
其中最早的三个是

\[
p=67369,\ 454969,\ 967129.
\]

紧凑结果保留所有例外、边界类及外源完整记录，并用完整记录数组哈希锚定；测试重新计算
整个范围后逐项比较该产物，见
[1000 万范围有限复现](../claims/type-II-pure-new-exception-dynamic-selector-10m-h100.md)。
它不是选择器定理，但将直接按定义审计真实 \(E_{\mathrm{new}}\) 的边界从
\((10^5,50)\) 推至 \((10^7,100)\)，并继续显示两个分支确实互补。尤其，最小缺陷尾所需
的最小尺度已到 \(q=714\)，所以后续统一证明必须允许状态依赖的尺度选择。

### 4.3 两条困难原进程的完整闭合

对两条没有固定因子外源桥的压力进程，直接在原始步长上分别取：

- 第一条固定取 \(q=15\)、\(d=37845=3^2\cdot5\cdot29^2\)，新增支持为
  \(\{29\}\)；
- 第二条固定取 \(q=90\)、\(d=121014=2\cdot3^6\cdot83\)，新增支持为
  \(\{83\}\)。

对每条进程，\(q\) 整除 \(B_0\) 与步长 \(P/4\)，\(d\) 整除 \(x_0^2\) 与
\(P/4\)，而 \(4q-1\) 整除 \(x_0+d\) 与 \(P/4\)。这些仿射不变量证明每个
\(n\ge0\) 都命中 T 分支且 \(\delta(p,q)\le1\)，不需要周期细化。两条原进程本原，
Dirichlet 定理还保证各含无穷多个核心素数。证明与精确审计见
[两条原压力进程的全体低缺陷尾](../claims/h19-k23-unbridged-pressure-full-low-defect-rays.md)。

因此 Selector-Pressure 已经建立。此前的子射线结果仍是正确的历史中间结论，但已被这个
全进程定理严格加强。两条进程仍是新分支的压力测试集，但不能挽回已在真实
\(E_{\mathrm{new}}(X,20)\) 上失败的 T/E 二分法。

## 五、严格证伪规范

### 5.1 如何证伪有限点上的选择器

对实际素数 \(p\)，一个合格反例必须同时完成：

1. 完整分解 \(B=(p-1)/4\)，枚举全部 \(q\mid B\) 与 \(k\mid B\)；
2. 对每个 \(q\)，完整分解 \(x_q=B+q\)，枚举 \(x_q^2\) 的全部相关除子，证明不存在
   支持缺陷至多 2 的 T 见证；
3. 对每个 \(k\)，完整分解外源乘积 \(M_k\)，枚举 \(M_k^2\) 的全部相关除子，证明
   E 同余无解；
4. 保存分解、枚举计数、零命中摘要和独立重放所需的全部数据。

只搜索固定 \(q\)、固定 \(k\)、固定因子菜单或一个截断的除子列表，不能构成反例。

### 5.2 反例意味着什么

一个满足上述标准的素数会否定当前“缺陷至多 2 或此外源出口”选择器，但不会否定
Erdős--Straus 猜想，也不会证明该素数没有其他 Type I/II 证书。三个已发现点应冻结当前
选择器版本；由于 T 的所有同余候选均为空，下一步必须增加真正不同的第三分支或更一般
的证书接口，而不是仅放宽支持缺陷。

### 5.3 如何反驳分析筛界

有限计算中的大量例外不能反驳只有渐近常数的筛界。有效反驳必须指出统一算术级数估计、
筛积双侧正则性、基本引理参数范围、余项估计或证书翻译中的具体失败。反过来，有限零遗漏
也不能升级密度定理为逐点定理。

## 六、停止规则

为避免继续堆积高命中率但低信息量的实验，后续工作遵守以下规则：

1. 自然区间扩算若没有增加新量词、产生新边界点或检验新分支，则停止；
2. 固定参数盒、固定 tail 菜单或固定来源菜单一旦已有 CRT、刚性或条件性逃逸障碍，则不再
   仅靠扩大常数推进；
3. 每个新实验运行前必须写明目标命题、完整反例定义、相对已有实验新增的量词，以及成功后
   能否转写为引理；
4. 选择器一旦出现合格有限反例，停止扩大同一版本的扫描，先分析最小反例；
5. 压力进程若连续扩展参数深度却没有新增同余状态、固定见证或反例，就停止扩层，转向符号
   分割；
6. 任何有限结果不得使用 `established`；任何仓库新证明不得仅因测试通过而标为外部核验。

## 七、知识库与 CI 收口

知识库应把数学结论与证据来源固化为机器可检查的接口：

- 所有新主张填写 `proof_provenance` 和 `review_status`；
- 定理账本由 `scripts/kb.py` 生成，并按状态、来源和审查层级分组；
- 计算结果卡必须记录脚本、参数、结果文件、算术模型、范围限制和独立重放命令；
- 综述中的数量和状态只引用生成结果，不手工复制；
- 本地相对链接替代指向可变 `main` 分支的 URL。

已落地的快速 CI 入口是
[research-kb-ci.yml](../.github/workflows/research-kb-ci.yml)。每次推送和拉取请求执行：

~~~bash
python3 scripts/kb.py validate
python3 scripts/kb.py build
git diff --exit-code -- index/timeline.md index/citation-graph.mmd index/theorem-ledger.md
python3 -m unittest tests.test_kb tests.test_type_ii_pure_new_exception_dynamic_selector
# 其余定向测试与 Ruff 文件清单见工作流
~~~

仓库完整测试面目前有数百项，并包含依赖大规模周期产物的复现；它保留为本地或定期全量层。
快速层仍必须逐字核对本轮 JSON 产物，不能只检查脚本退出码，也不能静默跳过结果一致性。

### M5：加入 AC 终端分支的替代接口（当前主目标）

三个反例的其他 Type II 证书已由 \(\max(A,C)\le2\) 的直接 AC 盒给出。下一步是将这种
终端短证书与 T/E 的严格递降明确区分，提出状态依赖的 AC 终端分支，并寻找或否定它在真实
筛例外上的全称覆盖。只有候选分支能逐点重放并经反例、压力进程与新的反例搜索后，才讨论
与变维筛证书合成为逐点接口。

## 最终优先级

1. 以三个反例的 \(\mathrm{AC}_2\) 终端证书为种子，定义状态依赖 AC 终端分支；
2. 在真实 \(E_{\mathrm{new}}\) 上寻找该第三分支的最小反例或可证明的因子选择律；
3. 保持 T/E 严格递降与 AC 终端解的角色分离，避免把终端证书误写为递降；
4. 只有新三分支经反例和压力进程检验后，才尝试与变维筛合成为逐点接口；
5. 只有新范围能检验新分支或新量词时，才扩大自然扫描。

当前最值得投入证明工作的对象是：能解释并严格递降三个已知反例的新证书机制，而不是
继续提高已被否定选择器的覆盖率。
