# Brauer-Manin obstruction for Erdos-Straus surfaces

## 定位

把方程视为仿射三次曲面上的整点问题，分析积分 Hasse 原理与强逼近的 Brauer–Manin 障碍。

## 主要贡献

- 识别 Erdos-Straus 曲面为奇异 log K3 曲面模型。
- 证明自然 Brauer 类不提供足以否定猜想的全局障碍。
- 说明同一障碍会妨碍某种强逼近，并统一解释经典二次互反限制。

## 证据与核查

- 已核对 arXiv:1908.02526 的主定理、局部点构造与结论部分。
- 几何结论是结构约束，不是每个 n 的显式整数点构造。

## 局限与后续

无 Brauer–Manin 障碍不等于整点必存在；不能把必要局部条件误写为充分条件。
