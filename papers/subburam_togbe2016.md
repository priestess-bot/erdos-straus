# A note on the Erdos-Straus conjecture

## 定位

研究互素正整数 c,n 的一般方程 c/n=1/x+1/y+1/z；出版社摘要称其给出解数 f(n;c) 的公式，并处理 Erdős–Straus 猜想的一个特殊 n 情形。

## 主要贡献

- 把三项单位分数解数写入一般参数 c 的框架。
- 出版社摘要报告一个特殊 n 情形的可解性。
