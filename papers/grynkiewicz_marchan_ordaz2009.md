# Representation of finite abelian group elements by subsequence sums

## 定位

这不是 Erdős--Straus 猜想的直接论文，而是分析 Type II 因子残数失败序列所需的
加法组合背景。本文研究有限阿贝尔群中的子序列和、加权子序列和及其周期结构。

## 本库实际使用的内容

- 第 567 页 Theorem C 给出多集合版本的 Kneser 定理。对
  \(A_i=\{0,g_i\}\) 应用它，可精确控制一个序列中落在子序列和集合稳定子群之外的项数。
- 第 566--567 页 Example 2 给出偶阶循环群的临界构造：正、负同一生成元的平衡和集
  恰好遗漏唯一的二阶元。这与本库否定“真子群加次线性异常序列”时使用的反例同型。
- 紧随其后的讨论把等号情形连接到 Kemperman 临界对和共同差算术级数，说明长异常部分
  可能高度结构化，但不能一概压缩成少量离群项。

## 证据与边界
