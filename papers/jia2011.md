# A Note on Terence Tao's Paper On the Number of Solutions to 4/p = 1/n1 + 1/n2 + 1/n3

## 定位

针对 Elsholtz–Tao 预印本的短注，研究素数平均解数中的一个和式估计；它属于计数技术链，而非猜想本身的逐点证明。

## 主要贡献

- 给出相关平均值估计的另一种论证。
- 与两天后提交的 arXiv:1107.6039 分属不同文本，均进入后续计数研究的参考链。

## 证据与核查

- 已取得并核对 arXiv 原文的定理与证明范围。
- 题名中的 Tao paper 是早期版本称呼；最终主论文由 Elsholtz 与 Tao 合著。

## 局限与后续

平均估计不能推出每个素数的解数非零。
