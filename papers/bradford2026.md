# A solution to the Straus Erdos conjecture

## 定位

声称用 Type I/II 同余类覆盖全部素数，但正文没有证明产生的无限同余类族确实覆盖所有 p=1 mod4。

## 主要贡献

- 从既有一变量公式为 Type I 和 Type II 推导可解同余类族。
- 列出 k=0 时若干具体剩余类和分解恒等式。

## 证据与核查

- 已核对全文：在第 4 页写道 The last thing that we must show is that this is a covering system。
- 其后仅观察 5,13,17,29 是前四个 1 mod4 素数，随即进入参考文献，没有覆盖性引理或归纳。

## 局限与后续

缺失命题正是从若干充分同余类到全部困难素数的主链，故不能视为证明。
