# The Inverse Problem Associated to the Davenport Constant for (C_2^2\oplus C_{2n})

## 本库使用的定理

论文第 3.5 节明确给出

\[
D(C_2^2\oplus C_{2n})=2n+2.
\]

它是 Girard--Schmid 秩三定理在 \(m=1\) 子族上的独立早期来源，并且还完整描述了
达到最大长度的极小零和序列结构。

## Erdős--Straus 选择器中的作用

对 Type II 缺口的单位素因子残数序列，\(C_2^2\oplus C_{2n}\) 的精确阈值为
\(2n+2\)。
达到阈值时必有共享单位子积；低于阈值只保留为 Davenport no-force 边界。该论文不主张
Erdős--Straus 结论，实际乘法残数和 marked lift 由本库独立核验。
