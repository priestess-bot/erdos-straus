# The estimate for mean values on prime numbers relative to 4/p = 1/n1 + 1/n2 + 1/n3

## 定位

同行评议的素数平均值估计；arXiv:1107.6039 是该工作的公开预印本，不能与 Jia 的另一篇短注 arXiv:1107.5394 合并。

## 主要贡献

- 证明 sum_{p<x} f_1(p) << x log^5(x) (log log x)^2。
- 改进 Elsholtz–Tao 早期版本对 Type I 平均和的上界。

## 证据与核查

- 已取得并核对 arXiv:1107.6039 的摘要、定理陈述及证明结构。
- DOI、卷期页 55(3), 465-474 由 Crossref 与 Springer 题录交叉核对。

## 局限与后续

这是平均值上界，不能推出每个素数都有解；其另一篇 arXiv:1107.5394 短注是不同智力工作。
